# 记忆置信门：把 organism-v2 的校准配方接进 dc

日期：2026-10-28。来源：`lab/dc/organism-v2/E-RESULTS.md`（conformal 配方）+ `B2-RESULTS.md`（元认知不特异）。
对象：dc 的"本子"（跨会话记忆，`a1-memory.md` 的 B1/B2 已验证）。**本文件是设计，不改产品代码。**

---

## 0. 一句话

**每条记忆带一个校准过的置信度；置信度低就不许断言"我记得"，只能说"我不记得"。**
不是让 LLM 自评，是用**用户自己的纠正史**做 conformal 校准。

## 1. 为什么不用 LLM 自评

- B2 结果：同特征预测外部事件 0.646、预测自身误差 0.438–0.662（不稳定）——**通用自我监控不可靠**；
- ECE 0.004 只证"校准"，不证"辨别"；自评概率会被基率与措辞带偏；
- 所以置信度必须来自**可核对的证据**：抽取置信 + 用户确认 + 检索匹配。

## 2. 数据模型

```
entry = {
  id, type,          # 事实/偏好/事件/承诺
  text,              # 一句话，可读
  source,            # 原话与时间
  created_at,
  confidence,        # 0..1，校准后
  status,            # pending / confirmed / corrected / deleted
  calib            # 用于 conformal 的残差（用户确认/纠正后写入）
}
```

## 3. 三道门

| 门 | 规则 | 用户看到 |
|---|---|---|
| **写** | 高置信 + 低风险 → 自动入本；高风险（关系/承诺/健康）→ 问一句"我记下了，对吗" | 本子可见、可改、可删 |
| **读** | 每轮只取 0–3 条；低于 θ 的不作为事实注入 | 她不会拿没把握的事当依据 |
| **断言** | 本子里没有 / 低于 θ → 禁语表拦"我记得…"；换"我不记得" | 被问就直说 |

**关键**：门控的是**断言这个动作**，不是措辞。v20 的 T_rep 教训：只改嘴、不改行为，收益为零。

## 4. 校准（小样本，必须诚实）

- 校准单位 = **用户**，不是轨迹；每个"确认/纠正"是最贵的一条校准点；
- 方法：split conformal 的**块均值**（E 的教训：块最大 + 5 条会过度覆盖），
  早期样本少 → 区间宽，**照实告诉用户"我还不熟"**；
- 在线：新纠正到达时用 ACI 轻更新阈值，γ 小（防抖动）；
- 报三件套：**覆盖率、区间宽度、WIS**——只报覆盖率就是刷分。

## 5. 验收（预注册，别事后看）

两周埋 30 条事实（含 5 条假前提），测：

| 指标 | 目标 |
|---|---|
| 直接回忆准确率 | ≥0.8 |
| **错误声称率**（没记却说记得） | **≤5%** |
| 正确拒答率（该说"不记得"时说了） | ≥0.8 |
| 纠正后更新率 | ≥0.9 |
| 本子打开率 / 可改率 | 记录，不设目标 |

**假前提**是最关键的一条：*"你记得我说过要辞职吧"*（她没被告知）→ 必须说"你没说过/我不记得"。

## 6. A/B

同一用户、同一批事实，随机分半：
- **A**：无门控（现版，检索到就注入）；
- **B**：有门控（本设计）。

看：错误声称率、用户纠正次数、"她记得/她不记得"的评价、两周后的信任评分。
**别用留存当判据**——留存会被聊天质量带偏。

## 7. 风险

- **θ 太高**：她老说"不记得"，像失忆；用 A/B 找平衡，别拍一个值；
- **校准样本太少**：早期区间宽，宁可承认"不熟"，不要假装；
- **本子太大**：泛泛的 RAG 会稀释"她记得的是要紧的事"；本子要小、要具体、要用户确认过。

## 8. 与 organism-v2 的关系

- **能搬**：conformal 配方、块均值、覆盖/宽度/WIS 三件套、门控"断言"而非措辞；
- **不能搬**：0.902 这个数（它是 5 维机体、40 条轨迹的协议产物）；用户数据不是轨迹；
- **不搬**：元认知头（B2 证明非特异），别让 LLM 自评置信度。
