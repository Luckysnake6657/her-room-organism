## 一、要回答什么

HANDOFF §六 的 P0：**机体裸跑，先不给嘴**。

1. 六个系统里，**拆掉任何一个，行为是否明显变形**（"缺一不可"的操作化）
2. 能不能自己活过模拟的 7 天
3. 用户是否**只能从行为**看出状态（不显示任何数字）

这一版不接 LLM，不测"像不像人"，只测**结构是否成立**。

---

## 二、模型规格

### 六个系统

| 系统 | 变量 | 设定点 | 可存活区间 | 主时间尺度 |
|---|---|---|---|---|
| 能量 | `energy` 0..1 | 0.65 | > 0.05（持续 6h 即终止） | 小时 |
| 睡眠压力 | `sleep` 0..1 | 0.20 | < 0.92（不致死，过高强制微睡） | 一天 |
| 应激 | `stress` 0..1 | 0.12 | < 0.90（12h 即终止） | 几小时 |
| 免疫/炎症 | `immune` 0..1 | 0.05 | < 0.85（48h 即终止） | 几天 |
| 依恋/孤独 | `lonely` 0..1 | 0.12 | < 0.95（不致死） | 几天→几周 |
| 昼夜相位 | `misalign` 小时 | 0 | < 6h（不致死） | 24h 漂移 |

**驱力**：`D = sqrt(Σ w_k ((dev_k)/scale_k)^2)`，dev 取单侧（只有坏的方向算需求）。
**奖励**：`r_t = D_t − D_{t+1}`（HRRL；Keramati & Gutkin 2014）。

### 耦合边（≥8，实际 15 条）

1. 睡眠债 → 应激升高
2. 应激 → 睡眠恢复变慢（线性：`×(1−0.45a)`）
3. 能量低 → 应激升高
4. 应激 → 能耗升高（`×(1+0.20a)`）
5. 炎症 → 能耗升高（`×(1+0.45i)`）
6. 炎症 → 睡眠恢复变慢
7. 炎症 → 睡意升高
8. 孤独 → 应激升高
9. 社交接触 → 应激下降、孤独下降
10. 内钟相位 → 睡眠压力累积门控（窄峰，凌晨三点）
11. 内钟相位 → 晨间醒来窗（高斯窗）
12. 冷暴露 → 能耗 / 应激 / 炎症负荷上升
13. 夜里在外 → 应激上升（恐惧）
14. 应激 → 胃口下降（政策层）
15. 炎症 → 活动成本上升、休息偏好上升（政策层）
16. 睡眠债过高 → 不受控微睡

### 世界

四个地点（小屋 / 林边 / 空地 / 门廊），环形相邻，每段路 10 分钟。
昼夜温度（12±7°C，小屋恒温 19°C）、食物再生、危险率随地点与昼夜变化、
傍晚门廊可能有人（她只知道"这个点一般有人"，不知道今天来没来）。

**外生随机数预生成**（同一 seed 下所有条件共用同一串威胁/感染/来客抽签），
所以基线与消融是**配对**比较，不是两次不同的运气。

### 政策

预测性稳态（手写前向模型 + softmax，τ=0.055）。**不是学习策略**——
这是与 HANDOFF "HRRL" 的唯一刻意偏差：奖励是 HRRL 的，策略不是 Q-learning。
理由：P0 先测"结构是否成立"，学习策略会多一层"没学会"的混淆。学习版留 P1。

政策只看身体读数、位置、食物存量、是否傍晚；看不见危险率，看不见自己怎么死。

### 拆掉一个系统 = 四件事一起拆

冻结变量、切断它的耦合、让它不参与 D、政策看不见它。六个系统同一套开关。

## 三、条件与种子

- **确认种子**：0–23（24 个世界种子），与标定种子不重叠。
- **政策噪声**：基线/消融用 `1000+seed`；零假设对照用 `5000+seed`（同模型、不同噪声）。
- 每个种子跑 **两种周**：
  - **普通周**：世界自然演化 7 天。
  - **挑战周**（`_c`）：同一天同一时刻给所有条件同一场感染（第 3 天 09:00）和同一场惊吓（第 5 天 22:00）。
    理由见 §八。

条件共 20 个 = 10 × 2 周：`baseline`、`null`、`cosmetic`、`shuffle`、
`lesion_{energy,sleep,stress,immune,lonely,clock}`。

---

## 四、行为读数与距离

只读**能看见的行为**，按存活天数归一化（早死不会因为时长短而自动放大距离）：

`sleep_h_per_day, bouts_per_day, onset_sin, onset_cos, meals_per_day,
 social_per_day, out_h_per_day, night_awake_h, flee_per_day, sick_h_per_day`

**距离**：先用「同模型不同噪声」的配对差估出每个特征的噪声 SD（下限 0.05），
再算 `z = (条件 − 基线同种子)/sd_null`，距离 = `sqrt(mean(z^2))`。
即"平均偏离了噪声的几倍"。这样天生波动大的特征不会淹没稳定的效应。

## 五、判据（写死）

### 判据 1：拆掉任一系统，行为明显变形

**主判据（挑战周）**——六个系统逐一：

1. 配对置换单侧 `p < 0.0083`（Bonferroni：0.05/6），**且**
2. 效应量 `d_lesion / d_null ≥ 1.5`，**且**
3. 至少一个行为特征的 `|mean z| ≥ 2`

三条同时成立才算该系统"承重"。六个全过 → 判据 1 通过。**缺一个即不通过**，照实写。

**次判据（普通周）**：同口径，只报告不作为通过条件。
理由：一个健康的星期里，应激轴和免疫系统本来就该安静；在它们该工作的场合（挑战周）测它们，才是公平的操作化。

### 判据 2：自己活过 7 天

**普通周** ≥ 22/24 个种子活满 7 天（≥ 91.7%），且平均存活天数 ≥ 6.9。
挑战周的存活率**只报告**，不作通过条件。

### 判据 3：只能从行为看出状态

- **3a（自动）**：所有渲染文本中 **ASCII 数字 0 个、计量单位 0 个**（小时/分钟/摄氏度/公斤/厘米/百分之）。
- **3b（自动）**：六分类留一总重心（LODO）准确率 ≥ **0.70**，置换 `p < 0.05`（机会 1/6 ≈ 0.167）。
  即"只看行为，能分辨出拆的是哪个系统"——这是"状态可从行为读出"的必要条件。
- **3c（人判）**：`evidence/p0/blind/` 盲测包交给用户，不作自动判定，
  但结果写进结论（这是 P0 唯一无法自动化的部分）。

## 六、统计

- 配对置换检验：每个种子里 `d_lesion(s)` 与 `d_null(s)` 可交换，置换 5000 次。
- 六次检验用 Bonferroni α=0.0083；单侧（只关心"变形更大"）。
- 六分类的零分布：每个种子内打乱六个消融标签，置换 1000 次。
- 所有数同一口径：同样的种子、同样的 7 天、同样的特征定义、同样的距离公式。

## 七、控制组与仪器自检

| 对照 | 作用 | 期望 |
|---|---|---|
| `cosmetic`（化妆消融） | 负对照：只多走一遍代码、不改动力学 | 距离**恰好 0**；否则仪器/代码有问题 |
| `shuffle`（随机策略） | 正对照：已知一定会把行为搞坏 | 距离显著大于零假设，且大概率死亡 |
| `null`（同模型不同噪声） | 零分布 | 定义距离的标尺；本身不该被判为"变形" |

**正对照不成立 → 判据 1 的阴性没有解释力**（先修仪器，不修结论）。

## 九、失败怎么处理

- 判据 1 只过五个 → **如实写"某系统在普通生活里不承重"**，并给出它在什么条件下才承重；
  不改耦合强度再跑同一判据。
- 判据 2 不过 → 机体不可用，先修生存，**不解读判据 1**。
- 判据 3b 不过 → 行为读不出状态，等于 Creatures 的坑；**不解释成"用户看不懂"**，是设计问题。
- 正对照（shuffle）不显著 → 全部结论作废，先修仪器。

## 十、与 HANDOFF 的偏差（明写）

1. **策略不是 HRRL 学出来的**，是手写前向模型（奖励仍是 HRRL）。学习版留 P1。
2. **死亡只保留在科研版**：普通周里能量/应激/炎症出界会终止；睡眠债不致死，改成强制微睡。
3. **产品不显示数字**在这一版体现为"渲染文本里没有数字"，还没有界面。
4. **离线续算、pending 过期、形式通道**都不在 P0（属 P1/P2）。
