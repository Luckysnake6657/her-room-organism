# P0b 结果：应激不是装饰，是 P0 的挑战不够密

跑数时间：2026-10-27（种子 0–23，与 P0 同一批）
预注册：`docs/p0b-stress-prereg.md`（跑数前冻结）
数据：`evidence/p0b/runs.jsonl`（432 次运行）、`analysis.txt`、`summary.json`

---

## 一、结论

1. **"应激是装饰"这个判断错了。** 它在 P0 的挑战周里确实没变形（1.29 倍），
   但在**密集威胁周**（每天夜里一场惊吓）里，拆掉应激让行为变形 **3.01 倍**（p = 0.0002）。
2. **不是六条边互相抵消。** 单边消融里，密集威胁周有两条边单独过线：
   - `stress_sleep`（应激→睡眠变浅）**1.56 倍**
   - `stress_immune`（长期应激→炎症）**2.22 倍**
   而"全拆"是 3.01 倍，**大于任何单边** → 边是叠加的，不是抵消的。
3. **P0 的失败是"世界不够狠"，不是"系统没接上行为"。**
   一场惊吓只影响一个晚上，七天平均下来当然看不出来。
4. **P0 判定不变**（按它自己预注册的判据，应激没过），但**解释要改**：
   不是"应激可拆"，是"应激要等到威胁密集时才看得见"。

## 三、为什么是这两条边

- **睡眠**：夜里被吓 → 应激高 → 睡眠变浅（`× (1−0.45a)`）。威胁密集时，睡眠债逐夜累积，
  第二天的活动、进食、见人全被拖慢。这是"慢性化"的第一条链。
- **免疫**：长期应激 → 炎症负荷（阈值 0.55）。密集威胁周里应激长期在 0.6–0.7，
  这条边把"烦"变成"病"，效果最大（2.22）。
- **不想出门**：阈值 0.55 太高，密集周也没怎么触发（0.64）→ 这条边实际上没接上。
- **想找人**：0.28，基本没用 → 和"心烦时更想找人"的直觉相反，
  因为我们给社交的加成太小（0.20×超出部分）。

**这是三条可以直接拿去改的具体线索**（要改，另立预注册）：
1. `stress_avoid` 阈值 0.55 → 0.35 左右，让"不想出门"真的出现；
2. `stress_social` 系数 0.20 → 0.45，让"心烦时想找人"压过"不想出门"；
3. `stress_appetite` 1.34 差一点，可略加（但它是"症状"，不是主承重边）。

## 四、和 P0 的关系（必须写清）

- P0 判据 1 的结论**不是错的**：在它预注册的世界里，应激确实不承重。
- 但把那个结论读成"应激是装饰、可以砍"**是错的**——这次实验推翻了它。
- 这正好是 P0 想避免的那种错误：**用一次实验的阴性去砍一个系统**。
  更准确的说法是：**应激的作用域是"威胁密集"，不是"普通一周"。**

### 对"选项 A（砍到五系统）"的修正

不推荐砍了。数据说它接上了行为，只是要等到威胁密集才看得见。
推荐改成：**保六系统，把"密集威胁周"作为标准测试条件之一**，
并按 §三 的三条线索做一次新的、单独预注册的耦合调整。

---

## 五、局限

1. 密集威胁周是**人为加的**（每天 21:00 一场）。它证明"应激能承重"，
   不证明"真实世界会这么密集"。真实世界的威胁密度需要另设参数。
2. `all_off` > 任何单边，说明还有**未测量的交互**（例如应激同时影响睡眠与免疫，
   两者再互相作用）。单边消融不能拆开这部分。
3. 仍然只有 10 个行为特征、7 天、一个世界结构。
