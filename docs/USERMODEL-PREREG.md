# 预注册：用户模型（预测他）

2026-10-31。目标：从真实互动估他的作息/回应/语气/雷区，给带置信的预测。

## 文献

- LLM 可从聊天历史推断用户人格（[arXiv 2604.19785](https://browse-export.arxiv.org/abs/2604.19785)）
- 对话中的人格预测（[ACM 2026](https://dl.acm.org/doi/10.1145/3776574.3831147)）
- 修复请求识别（[Mm, Wat?](https://hal.science/hal-05335583v1/preview/2555_Mm_Wat_Detecting_Other_in.pdf)）
- 主动支持需要用户建模（[Proactive 综述](https://par.nsf.gov/servlets/purl/10580599)）

## 预测什么

1. **他什么时候在**：按小时活跃概率 P(active|hour)
2. **他回得快不快**：近 30 天回应延迟分位数
3. **他语气倾向**：句长、标点、负向词比例
4. **话题雷区**：提到就冷淡/变短的话题（先只统计，不判定）

## 判据

- 作息预测 AUC ≥ 0.70（按天留出验证）
- 与随机标签对照 AUC ≈ 0.5
- 延迟估计误差（中位数）≤ 5 分钟

## 边界

- 只用时间戳和文本长度/标点，不做情绪推断
- 不存原始消息，只存聚合统计
- `usermodel.enabled=false` 即回滚
