# 记忆可靠性：方案与判据

目标：**会认错、少嘴硬、记得更多。**
判据：接住率 ≥70%、自信说错 <5%、说"没记" <15%、纠正后不再犯 >90%。

## 文献

- Chow 1970：拒识与错误代价的权衡
- Geifman & Elidan 2017：selective prediction
- Guo et al. 2017：置信校准
- Kadavath et al. 2022：模型对"自己知道什么"的判断
- Lewis et al. 2020：RAG；Ji et al. 2023：幻觉综述
- Hyland 1998：学术语篇中的模糊限制（hedging）

据此：**错误的代价远高于空答**，所以先做"该弃权就弃权"，再谈召回。

## 一、置信分层（已实现）

`organism/memory_policy.py`：

| 档 | 条件 | 行为 |
|---|---|---|
| assert | score ≥0.55 且 calibrated ≥0.70 | 正常说 |
| hedge | score ≥0.30 | "我记得好像是…" |
| none | 其它 | "这个我没记" |

服务层：`/context` 返回状态里带"（记忆不太确定）"，并写
`evidence/p3/memory_decisions.jsonl`（时间、查询、档、条数、top 分）。

## 二、抽取与查询

- 原子化：谁/什么/何时，一条一事
- 查询改写：口语 → 实体 + 意图
- 重复指代（"上次那个"）→ 最近未完成事项

## 三、检索

- 阈值 0.3（已定：gold 90%，本子外垃圾 0.4）
- 混合：字面 + 字符 n-gram + 向量（向量换 chunk 再试）
- 重排：只排 top10，说"无"回退字面 top1（已做）

## 四、纠错闭环

- 纠正一次 → 该条 calibrated=0 → 永不断言
- 冲突条目一起降权
- 目标：纠正后不再犯 >90%

## 五、评测（必须重复）

- **100 道人工题**：从真实记录出，口语化，允许等价答案，含"无"选项
- **每题 3 次**独立运行（不同改写/种子），报中位数与 IQR
- 单次结果不作结论；判据先写死
- 同时记录：接住/对冲/弃权/自信错

### 100 题设计要点

1. 通俗：用"你还记得我上次说要去哪吗"这种问法，不用书面语
2. 完整：每题给全上下文线索，不缺主语/时间
3. 有"无"项：确实没记的事要能答"没记"
4. 不泄漏：不出现"隔了 X 秒"这类元信息
5. 覆盖：生活/承诺/偏好/关系/工作各 20 题
