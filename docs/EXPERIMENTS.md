# 实验原理与结果

这份文档说明：每个结论是怎么测出来的、判据是什么、哪些是阴性、哪些只是设计假设。

## 总原则

1. **先写判据，再看结果**（预注册）。每个实验的判据在跑之前写死在 `docs/*prereg*` 里。
2. **有对照**。不给"跑了一下感觉不错"当证据。
3. **可复现**。`python -m organism.test_invariants`（45 组）+ `python -m organism.contract_tests`（50 条）。
4. **阴性照写**。失败、不显著、方法错了，都记录，不粉饰。
5. **不声称意识**。只测行为与机制，不把"像"说成"是"。

## 一、身体（P0 / P0b）

**问题**：六状态（能量/睡眠债/应激/免疫/孤独/昼夜错位）是否承重，而不是装饰？

**设计**：
- P0：消融实验，逐个冻结变量，看行为与生存是否退化。
- P0b：威胁密度对照（std vs dense），看应激是否只在密集威胁下承重。

**判据**：消融后至少一项指标显著退化；dense 下应激相关指标显著上升。

**结果**：
- P0：5/6 条判据通过；生存 23/24。
- P0b：dense 下应激承重（stress→sleep 1.56×、stress→immune 2.22×；总体 3.01×）。
- 产品 30 天对照：dense 使生病分钟 +64%、威胁 2.0×。

**结论**：六状态在密集威胁下承重；平静世界里应激偏弱，这是已知限制。

## 二、离线与连续性（P1）

**问题**：关掉再开，是否等价于"一直活着"？

**设计**：同一存档，按挂钟补算，和一直运行的逐位对比。

**结果**：离线补算与连续运行**逐位一致**。
**限制**：补算只补身体，不补那几天的日记/巩固（成长有断档）。

## 三、形式通道（P2）

**问题**：延迟/字数/主动能否由身体算出来，而不是模型演？

**结果**：
- 延迟由 D、U、人物卡决定，范围 8–300 秒；
- 字数由 D、慢性、U 决定，有上下限；
- 主动由孤独 + 慢性 + D 决定。
**测试**：45 组不变量里覆盖了边界与单调性。

## 四、可读性（3c）

**问题**：只看文字，能不能读出她的状态？

**设计**：三种状态（好/中/差）× 多段对话，A=完整、B=只内容、C=只形式；多个判读者盲评。

**结果**：判读者打分与真实 D 的 Spearman ρ = 0.83 / 0.93 / 0.88（均值 0.88，sd 0.04），读者间 0.84–0.93。
**失败项**：C 条件里写了"隔了 X 秒才回"，秒数本身泄漏状态，判据 3 无法通过。
**结论**：状态可读；但"形式增量"的测试设计有缺陷，不能声称已证明。

## 五、记忆（P3）

**问题**：记忆能否无损迁移、准确检索、不知道就拒绝？

**结果**：
- 完整性：源 273 条 / 导入 273 条，缺 0；
- 检索：50/50（自造关键词查询）；
- 未知查询：0 命中，走"这个我没记"；
- 字面重叠检索 54%；本地向量（bge-small-zh）仅 18%，**阴性，不接入**。
**限制**：查询是片段，真实问法未标注；检索质量仍是主要瓶颈。

## 六、校准

**问题**：她说"我记得"时，置信是否等于准确率？

**设计**：分箱均值校准；用户确认/纠正作为标签。

**结果**：ECE 从 0.150 降到 0.052；纠正 10 次后，该条记忆校准置信降到 0，不再被检索。
**限制**：需要 ≥10 条反馈才生效；目前真实反馈很少。

## 七、成长

**问题**：成长是非线性的吗？

**判据（预先写死）**：
- 巩固：第 3 个不同天才出现候选（0,0,1）；
- 习惯：14 天内 ≥3 次才形成（0,0,≥1）；
- regard：连续正面互动，增量递减；
- U：失联时饱和上升（凹、<0.75）；
- 遗忘：45 天强度减半。

**结果**：五条全部符合（测试第 43 组固化）。
**失败/修正**：
- 巩固原来按"条目数"计数，一天说三遍就触发 → 改为按"不同天"；
- 加速回放原来用墙钟，导致窗口对不上 → 改为模拟时间。

## 八、BDI 注入

**问题**：把"他在忙什么/想要什么/以为什么/情绪"注入提示词，回复是否更像她？

**设计**：同一批消息，基线 vs 注入，盲评 20 对。

**结果**：注入版胜 12/20 = 60%（弱通过；95% 区间约 39–78%）。
**失败/修正**：
- 抽取最初把"他在问"当成"他在做什么" → 加规则，只写生活/工作活动；
- 缺情绪字段 → 加 mood。

## 九、介入定价

**问题**：什么时候该说话、说多少？

**理论**：Horvitz 1999；An TMLR 2026（intervene iff 收益 > 打断成本）。

**方法**：
```
benefit = 0.5·明确度 + 0.3·价值 + 0.2·关系
cost    = 0.35·应激 + 0.25·(1−精力) + 0.2·D/2 + 0.1·U
net     = benefit − cost − 不确定惩罚
```
输出 now / brief / later。

**阴性结果**：先试过 life/task 关键词分类，调参集 97%，**留出集只有 43%**，方法不成立，已废弃。
**限制**：阈值按分布选，没有 outcome 标签，不能声称决策正确。
