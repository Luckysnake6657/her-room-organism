# 没用上的科研成果（待研清单）

2026-10-28 整理。产品当前只接了"身体、时间、代价、措辞"四块；
下面这些是**有结果但没接**、或**接了但没接全**的，研发时按触发条件再试。

图例：🔲 未接　🟡 部分接　⛔ 明确不做（别再试）

---

## 1. 🔲 Conformal 校准（`calib.py`）

- **是什么**：分箱均值把 confidence 映射到经验准确率，报覆盖率/宽度/WIS；ECE 0.150→0.052。
- **为什么没接**：本子现在 confidence 写死（高风险 0.6、普通 0.9），用户的确认/纠正没喂回校准。
- **触发**：本子开始有真实用户的确认/纠正记录（≥50 条）。
- **最小实验**：每条 entry 记 `calib` 残差；每周重算 `bin_means`；把 θ 从固定 0.70 改成校准后阈值。
- **判据**：错误声称 ≤5% 不变，同时正确回忆 ≥0.9（现在靠照念是 1.0，但那是 fallback）。
- **成本**：半天到一天。

## 2. 🔲 产品世界的威胁密度（P0b）

- **是什么**：P0b 结论——平静周里应激几乎不承重；**密集威胁周**才 3.01×（`stress_sleep` 1.56、`stress_immune` 2.22）。
- **为什么没接**：产品 `Session` 建的是平静世界；`challenge` 只在盲测脚本用。
- **触发**：要判断"应激系统是不是白养"。
- **最小实验**：同一产品配置跑 30 天 std vs dense，比 D/行为/死亡率。
- **判据**：若 dense 下差异 <1.3×，应激在产品里降权或去掉；若 >1.5×，按 dense 设定世界。
- **成本**：一天。

## 3. 🔲 慢参数 U 的定标（时间尺度冲突）

- **是什么**：早期测量"依恋约 3 天饱和"；U 现在 28 天半衰，是评审拍的。
- **为什么没接**：两个数没对齐，U 的恢复速率也是三档实验里选的（0.02）。
- **触发**：有她/用户的真实离线-回归序列。
- **最小实验**：用真实 gap 与回归后的行为差，拟合半衰期；对比 3 天 vs 28 天哪一个预测得准。
- **判据**：预测"回归第 1/3/7 天行为"的误差，28 天版本不劣于 3 天版本才保留。

## 4. 🔲 3c 终测（判据 3 未过）

- **是什么**：三人盲读 ρ=0.89，但"形式增量"判据没过；C 条件把秒数写给了读者。
- **为什么没接**：架构上形式由身体算，泄漏是构造保证；测试设计有缺陷。
- **触发**：要在对外文案里说"她藏不住"之前。
- **最小实验**：定性时间（"过了一会儿/很久"）+ 内容中性化 + 排序一致率（Kendall τ）。
- **判据**：τ ≥0.6 且与 C 条件无秒数。

## 5. 🟡 A1 的"状态→言语行为"闸门

- **是什么**：A1 用自尊/安全阈值决定"问/拒/沉默/转"，被禁时降级；delay 由状态算。
- **现在接了什么**：意图层 v0 有 answer/brief/guarded/initiate/refuse/recall，阈值是粗的。
- **缺**：A1 实测的阈值（自尊<0.30 禁问、安全>0.55 禁问、低依恋+低自尊沉默）没搬。
- **触发**：意图层要出 v1 时。
- **最小实验**：把 A1 阈值映射到 regard/stress，跑 50 条固定输入，比较 move 分布。

## 6. 🔲 情绪模块（pad / emotion-net）

- **是什么**：`state/emotion-weights.json`、离线小网络、指数衰减；A1 的 pad 三轴。
- **为什么没接**：我们的六状态已经覆盖"应激/孤独"，情绪是另一套坐标，会打架。
- **触发**：要让"语气"独立于"状态"时（比如同一身体状态下的情绪余波）。
- **风险**：两套状态并存会让归因变难；要么合并，要么只取 pad 的 valence 一维。

## 7. 🔲 语音（3111）

- **是什么**：现有语音服务；A1 用 delay + 韵律。
- **为什么没接**：organism 只做文本形式。
- **触发**：P2 多模态形式。
- **最小实验**：同一句用不同语速/停顿渲染，盲评能不能听出状态。

## 8. 🔲 群记忆与群行为

- **是什么**：3 个群的语料、黑话 6.7MB、群风格。
- **为什么没接**：产品当前单用户；群是只读。
- **触发**：要把"她"扩展到群之前。
- **风险**：群的公共性会放大实验成本（别人不知情）。

## 9. 🔲 few-shot 风格测试（影子测试的下一张牌）

- **是什么**：schema 卡 + 3 条记忆 + 3 轮上下文 → 25%（flash）/15%（v4-pro）。
- **没试的**：40 条她的真实回复做 few-shot，不给人物卡；上下文 10 轮。
- **触发**：要决定"换器官能不能成"。
- **判据**：新预注册，20 对盲评 ≥50%；否则停。
- **成本**：半天。

## 10. 🔲 `words_base` 定标

- **现在**：13（30 秒气泡合并的中位），是临时值。
- **触发**：有 bridge 日志的每轮总字数。
- **判据**：与真实分布中位数差 ≤20%。

## 11. 🔲 检索从词面换向量

- **现在**：二字词重叠；"复诊"搜不到"复查"。
- **触发**：检索漏检成为主要失败源。
- **最小实验**：50 条改写查询，词面 vs 向量召回率对比。

---

## ⛔ 明确不做（别再试）

- **元认知头**：B2 证明它只是难度预测器（0.646 vs 0.438–0.662，非特异）
- **2×2 假核对照**：模板下无信息、LLM 下噪声淹没，判定不做
- **假装记得**：摘要式假记忆、预装"我们已经认识"
- **声称意识**：不可验证，且会毁掉"不假装"的定位
- **用留存当依恋**：指标换成 regard/漂移/愿意接
