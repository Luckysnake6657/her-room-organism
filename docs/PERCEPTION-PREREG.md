# 感知层（最小）：预注册

2026-10-30。只做两件：内感受、在场感。

## 文献

- Seth 2013 / Barrett 2017：内感受推断，身体状态是感知
- Endsley 1995：态势感知（感知→理解→预测）
- Zacks & Tversky 2001：事件边界（本轮不做）

## 做法

### 内感受（身体 → 感觉词）

只在信号超过阈值时输出，不编造：

| 信号 | 说法 |
|---|---|
| 能量 <0.35 | 有点累 |
| 饱腹 <0.4 | 有点饿 |
| 应激 >0.6 | 心里有点紧 |
| 免疫 >0.5 | 不太舒服 |
| 睡眠债 >0.5 | 没睡够 |
| 孤独 >0.6 | 想找人说话 |

### 在场感（social-v2 时间戳）

- 最近一条消息 <5 分钟 → "他在"
- 距上条 >6 小时 → "他有一阵没来了"
- 其它 → 不说

## 判据

- 阈值以下不输出（防"装感觉"）
- 每条最多 2 个感觉词，避免堆砌
- 不改变记忆/检索，只影响提示词
- 测试：饥饿/在场各 2 组边界
