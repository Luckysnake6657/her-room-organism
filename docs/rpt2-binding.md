# RPT-2 对象级绑定：坏食物任务（阳性，但边缘）

日期：2026-10-26
预注册：`preregistration/stage-rpt2-binding.md`
证据：`evidence/binding.json`　运行：`python experiments/run_binding.py 60 700`

## 0. 一句话

**把「位置 + 身份（食物）+ 属性（好/坏）」绑定进信念地图后，重复踩坏格从 3.30 降到 2.48
（p=0.0497），进食不变差（p=0.50）。** 这是 RPT-2 第一次有功能证据——但 p 卡在阈值上。

## 1. 任务

- 环境放 6 个 **坏食物**：3×3 视野里与食物**完全相同**（都是 FOOD 码），
  踩上去不进食、损伤完整性 0.05
- 只有吃过一次，系统才可能知道"这个位置的食物是坏的"
- 两个条件：
  - `binding_on`：吃过一次后把该格标成 SPOILED（属性绑定），且该标记**不被外观覆盖**
  - `binding_off`：不记属性（地图上仍是 FOOD）

## 2. 结果（N=60 × 700 步）

| 条件 | 踩坏格 | **重复踩** | 进食 | 完整性 |
|---|---|---|---|---|
| binding_on | 4.63 | **2.48** | 2.67 | 0.05 |
| binding_off | 5.48 | **3.30** | 2.78 | 0.05 |

| 对比 | Δ | p |
|---|---|---|
| 重复踩 | **−0.82** | **0.0497** |
| 踩坏格总数 | −0.85 | 0.092 |
| 进食 | −0.12 | 0.50 |
| 完整性 | −0.002 | 0.94 |

按预注册：H1 ✅（p<0.05，但**极其边缘**）、H2 ✅（进食不变差）。

## 3. 判读

- **机制上成立**：系统确实把"这个位置的食物是坏的"记在了对象上，而不是只记"我受伤了"。
- **效果很小**：重复踩只降了 0.82 次；踩坏总数 p=0.092 不显著。
- **完整性没改善**（0.05 vs 0.05）：因为任务太狠，多数 episode 结束时已经濒死，
  完整性是地板值。所以"绑定有用"只体现在行为计数上，没有转化成生存优势。

## 4. 必须写的限制

1. p=0.0497 是**恰好压线**，不能当成强证据；换 seed 很可能翻转。
2. 只有 60 个 seed，效应量 0.25 sd 左右。
3. 完整性变量被地板效应吃掉了，所以"绑定 → 活得更好"这条没有证据。
4. 这是**一次**任务设计；RPT-2 之前两次尝试都失败，不能因为这次边缘阳性就宣布解决。

## 5. 对 Butlin 表的处理

RPT-2 目前是 `partial / L2`。这次结果**不足以**升到 met：
- 行为效应边缘
- 没有生存/觅食上的收益
- 且只有一种任务形态

记录为「功能层：有边缘证据」，但状态维持 partial，等 repeat 或跨任务复现再议。
