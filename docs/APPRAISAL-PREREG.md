# 预注册：评价融合权重（先验，不拟合）

2026-10-31。感受由多因素合成，不允许单一传感器决定情绪。

## 输入

身体六状态、摄像头在场/光线、他的话、记忆档位、关系。

## 先验权重

| 因素 | 权重 | 说明 |
|---|---|---|
| 摄像头看到人 | +0.08 | 确认在场 |
| 长时间没看到人（≥30 分钟） | **−0.18** | 缺席 |
| 独处太久（叠加） | −0.08 | 孤独 |
| 屋里很暗 | −0.05 | 环境 |
| 他的话里有求助/靠近 | +0.04 | 社交信号 |
| 他刚回来（<5 分钟） | +0.06 | 重聚 |

权重之和限制在 [−0.25, +0.25]；关系越远，传感器影响越小（群聊 ×0.3）。

## 判据

- 单独看摄像头，不能把效价从正推到负（必须叠加身体/时间）
- 方向正确：长期缺席 → 效价下降；他回来 → 上升
- 66 组测试里新增两条方向检查

## 回滚

评价融合只影响 affect 的输入；`affectSelf=false` 即不注入。
