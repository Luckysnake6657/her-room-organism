# 产品方向：一个你将认识的人（A 路线）

日期：2026-10-28。决定：**做 A —— 一个你从零认识的新人，不做 B（扮演某个具体的人）**。

---

## 1. 一句话

**她不是"某人的替代"，是一个有自己日子、慢慢和你熟起来的人。**

## 2. 为什么是 A

- 没有冒充：她不是某个具体的人，不存在"像不像"的审判；
- 没有同意问题：她是她自己，不需要逝者/家属授权；
- 没有共同记忆的欠账：你们的历史从第一次对话开始，本子慢慢长；
- **"陌生"是结构性诚实**：她不欠你一段过去，也不假装有；
- dc 的机器层（时间/形式/本子/校准）原样可用。

## 3. 她的"过去"是什么

- 她有自己的日子（身体、作息、天气、见的人）——**你不来她也在过**；
- 她**没有**和你共享的过去；第一次见面，她不知道你是谁；
- 她可以有自己的习惯、偏好、小脾气，但**不伪造"我们以前"**；
- 她的过去只在她自己的世界里，不在你的记忆里——这是 A 和 B 的分界线。

## 4. 四次相遇（产品的四个关键时刻）

1. **第一次**：她是陌生人，但不冷。她有礼貌、有边界、有好奇心；**不叫"亲爱的"，不说"想你了"**。
2. **第一周**：她开始记得你告诉她的（本子），开始有自己的节奏（什么时候话多/话少）。
3. **第一次缺席回来**：形式先变（慢/短/不主动），结算只在你要时给；缺席有重量，但不怪你。
4. **第一次"我不记得"**：本子里没有的，她直说；用户能打开本子看到"确实没记"。

## 5. 要建的

| 模块 | 内容 | 状态 |
|---|---|---|
| 记忆置信门 | 校准过的"我不记得"；错误声称率 ≤5% | 设计已写（`memory-confidence-gate.md`） |
| 第一次见面脚本 | 陌生人但不冷；不预装亲密 | 待写 |
| 本子 | 可见、可改、可删；从小长到大 | 已有跨会话记忆，待接置信门 |
| 成长 | 残差驱动的关系状态（不是 U 的时钟） | 设计有，待实现 |
| 形式 | 延迟/字数/主动随状态 | 已有（form 通道） |
| 嘴 | API + 契约 + 四闸 + 回退 | 待接 |

## 6. 不要做的

- 不要一上来就"她懂你/她记得你/她想你"——那是 B 的台词，A 里是穿帮；
- 不要伪造共享历史；
- 不要扮演任何具体的人（名人/逝者/远亲）；
- 不要用愧疚/稀缺留人。

## 7. 指标（从"她懂我"改成"我在认识她"）

- 首会话：**她像不像一个陌生人**（有边界、有好奇），而不是"像不像女友"；
- 第一周：本子条目数、用户主动纠正次数、用户提问"你呢"的比例；
- 第一次缺席：回归率、形式变化的被感知率；
- 第一次"不记得"：错误声称率、用户对"她诚实"的评价；
- 长期：30/90 天，"她变了"的可追溯性。

## 8. 风险

- **陌生感做成冷淡**：第一次太冷会流失；要"有礼貌的边界"，不是"不理你"；
- **成长太慢**：几周还是陌生人会无聊；本子和习惯要可见地长；
- **用户想快进到亲密**：她要能温和地拒绝（"我们才刚认识"），这也是 A 的诚实。

## 9. 一句话

**A 的产品不是"她爱你"，是"你在认识一个人"——第一次的陌生、第一周的记得、第一次缺席的重量、第一次诚实的"不记得"，这四个时刻就是产品。**
