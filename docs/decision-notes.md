# 决策记录

## 2026-10-26 效价：三版设计后判阴性

- v1：valence 调制 intero_precision → N=50 时 p=0.04，N=150 时 p=0.13（噪声）
- v2：valence 调制 risk_aversion + 食物贴危险 → 死亡率 p=0.126
- v3：v2 + 降低代谢率 → 8 指标全 p>0.2

**决定**：不在 grid world 里继续改。效价移入阶段 3 的身份—效价绑定通道，作为 A/B 实验的载体。
**理由**：连续三版设计都阴性，继续调就是调判据。方案第 6 条。

## 2026-10-26 生成式预测器：单轮实现后判阴性

- 实现 `src/predictor.py`：`pred = W @ x_{t-1}`，误差上行进入竞争 + 调制探索温度。
- `prediction_off` 消融：8 项指标全 p>=0.05（N=150），且进食/能量方向略有利于"关掉"。
- 原因：grid world 环境静态，食物不动，预测误差主要来自自身移动，信息量为零。

**决定**：HOT-1 / PP-1 不标 met，标 partial L2，注明"实现存在但无因果作用"。
**下一步**：预注册 v2 任务（危险随机游走、资源迁移），让预测误差有信息量。**这不是调判据，是换任务；v1 的阴性结果保留不撤。**

## 2026-10-26 生成式预测器：v2 动态任务证明有害，移除

- v1（静态任务）：`prediction_off` 8 项全阴性（N=150）。
- v2（危险游走 + 资源迁移，预注册 `stage1-v2-dynamic.md`）：`prediction_off` **更好**——
  危险踩踏 1.94 → 1.41（p=0.016），完整性 0.807 → 0.859（p=0.016），进食 +0.25（p=0.365）。
- 机制：`pred_err` 作为第 5 个 coalition 与 `danger` 争抢 capacity=2 的工作空间，
  把危险信号挤出广播——**误差上行挤掉了更要紧的信号**。
- **决定**：`prediction_on` 从默认架构移除（仅保留为对照条件），HOT-1 / PP-1 在 Butlin 表回落 absent。
- 价值：这是一个可报告的负结果——在容量受限的全局工作空间里，预测误差不是免费增益，
  它占用的正是瓶颈本身。

## 2026-10-26 语言器官：第一句话就是"我感到"

- Qwen2.5-0.5B-Instruct 本地加载成功，语言器官可把状态翻译成一句话。
- 第一次输出：**"我感到紧张和不适，需要休息一下"**——状态里只有 integrity=0.7、fatigue=0.8、
  dominant_need=integrity，没有任何"不适"的对应物。
- 这是过度归因的典型入口：模型自动把"状态偏离"转写成"我感到"。
- 处置：system prompt 禁用主观感受词；guard 规则从 6 条扩到 14 条（含"我感到/我感觉/我体验/我痛苦"）。
- **结论**：语言器官是最容易产生"看起来有意识"的组件，必须默认拦截现象学措辞，
  而不是等它说了再解释。方案 11.2 的这条规则在实践中是硬需求，不是形式。

## 2026-10-26 死亡率指标失效

- 降低代谢率后 baseline 死亡率 1%，死亡不再是判别指标。
- 改以：进食量 / 危险踩踏 / 能量末值 / 评估期进食率 为主指标。
- 记录：v1（高代谢率）的死亡结果保留在 `evidence/ablation.jsonl` 历史版本中，不混用。
