# 记忆抽取：按证据改，不按感觉改

2026-10-28。起因：自动抽取把一整段话当一条事实塞进 pending。

## 三条判据（来自综述）

> Colaco & Lahjouji, *What to Keep, What to Forget: A Rate–Distortion View of
> Memory Compaction in LLMs and Agents*, arXiv 2607.08032.
> <https://ar5iv.labs.arxiv.org/html/2607.08032>

1. **P-rev 可逆**：反复做不可逆的摘要，误差超线性增长；能取回原文的记忆保持平稳。
2. **P-q 查询条件**：决定"留什么"时看得到查询，比看不到好一个互信息间隙。
3. **P-fid 保真分级**：原文 / 近无损 / 有损 / 多级，要明确自己在哪一级。

## 我们的设计怎么对应

| 判据 | 做法 |
|---|---|
| P-rev | 抽取**只新增** pending，原文永不删；遗忘只标 faded，不删条目 |
| P-q | 检索按当前消息打分；抽取按"他这句话里关于他自己的事实" |
| P-fid | 事实条目原文照录，不改写；摘要只出现在 consolidation，且保留源条目 |

## 抽取规则（v1）

- 只收**原子事实**：一个分句、一个主语（我）、一个谓词
- 长度 4–30 字；超过的不收（避免整段入库）
- 问句、第三人称（"他说…"）、当下感受（"我今天有点累"）不收
- 高风险（医院/药/辞职/借钱/结婚…）→ pending，问一句再确认
- 同一批去重；每条最多 3 个

## 测试（第 35 组）

- `我喜欢逃课，我周三要去医院复查` → 两条
- `我今天有点累` → 空
- `他说我喜欢猫` → 空（第三人称）
- `我喜欢猫吗？` → 空（问句）
- 长段落 → 不产生整段条目
- **反复 sweep 10 次，所有条目原文不变**（可逆）

## 还没做的

- **LLM 抽取**：规则召回有限（隐喻、跨句指代抓不到）。Mem0/Generative Agents 用模型判断显著性，我们还没接；接之前要先有精确率评测集
- **时间归一化**："周三"没有落到具体日期；P-fid 要求原文保真，但检索需要可比较的时间
- **精确率评测**：需要人工标 50–100 条，算 precision/recall；现在只有构造用例
