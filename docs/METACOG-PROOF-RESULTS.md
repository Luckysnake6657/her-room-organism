# 元认知结果：监控成立，控制成立

2026-10-31。预注册见 `METACOG-PROOF-PREREG.md`。

## 实验 1：监控（quiz100，80 题）

| 判据 | 值 |
|---|---|
| 准确率（top1 严格） | 85.0% |
| type-2 AUC | 0.787 |
| meta-d' | **1.128** |
| 打乱对照 95% CI | [−0.67, 0.58] |
| **M-ratio** | **0.544**（>0.5 ✅） |

结论：置信包含超出难度解释的信息；**监控成立**。

## 实验 2：控制（80 题 × 2 条件 = 160 次）

只改内部置信，不提示“可以反问”。

| 条件 | 核实率 |
|---|---|
| 高把握 | 18.8% |
| 低把握 | **51.2%** |

- 差值 **+32.5 个百分点**（判据 ≥15 ✅）
- Fisher **p < 0.0001** ✅

结论：置信因果地改变核实行为；**控制成立**。

## 边界

- 置信是提示注入，不是真实内感受；测的是“表达出的把握”对行为的影响
- 核实率用正则判定，含“什么/哪/吗”等，两组同规则，差异仍有效
- 单一用户、单一模型；未做外部复现

## 现在可以说

> 系统具备元认知的**监控**与**控制**两个功能成分，且有消融级的对照证据。
> 不声称主观体验；也不等于 HOT 式的“关于表征的表征”已被证明。
