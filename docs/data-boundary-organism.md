# 数据边界 v0（organism 这条线）

2026-10-28。接 API 之后，用户的话会出机器；这份文件记清"存在哪、发什么、怎么删"。
（`docs/data-boundary.md` 是 lab-home 那条旧线的，不要混。）

---

## 一、存在本地的

| 数据 | 位置 | 谁可改 |
|---|---|---|
| 身体与世界状态 | 会话存档 JSON | 程序 |
| 你告诉过她的事 | 本子 JSON（条目、置信度、状态） | 用户可看/改/删 |
| 会话往来 | 只在内存与存档里，不单独留存聊天记录 | — |

## 二、发出去的（每次回话）

- 她的状态摘要（人话，无数字）
- 本子上与本轮相关的 0–3 条
- 你刚说的那一句

**不发**：账号、其他文件、API key、历史聊天全文。

## 三、命令

```
python -m organism.data --session <存档> --notebook <本子> --what
python -m organism.data --session <存档> --notebook <本子> --export backup.json
python -m organism.data --session <存档> --notebook <本子> --delete --yes
```

- 导出：一个 JSON，含 session 与 notebook，**不含 API key**（key 是设备配置）。
- 删除：删存档与本子，删完**再查一遍**，`ok=True` 才算删掉。
- 删除不可恢复，必须 `--yes`。

## 四、还没做的

- **加密**：本地明文。要做需要密钥管理。
- **API 侧日志**：我们不发送全文，但服务商侧的留存看它的条款。
- **导出格式版本号**：字段变了以后，旧导出要能读。
- **删除的彻底性**：只保证文件被删；SSD 旧块不在我们控制内，文案不能承诺"物理抹除"。

## 五、对外能说的 / 不能说的

能说：

> 她只把这台电脑上的存档和本子存在本地；每次回话只发送状态摘要、相关的几条本子、
> 和你刚说的那句。可以导出，可以删除，删完会验证。

不能说：

- ❌ "我们不留任何记录"（发出去的会经过服务商）
- ❌ "删了就彻底不存在了"（只能保证文件被删）
