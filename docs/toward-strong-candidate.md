## 2. 按 IIT 标准：任务 agent 不成立，小网络里能找到 Φ

| 对象 | Φ（PyPhi） | 备注 |
|---|---|---|
| dc 任务 agent（3 模块） | **0.004–0.011** | 与打乱零模型不可区分 |
| dc2 进化小网络（4 节点） | **0.93** | 但那是玩具，没有任务 |
| n=5 随机网络（K=3） | 0.84 | 同上 |

**任务 agent 的 Φ≈0 是架构性的**（模块竞争 + 可展开），换任务、加耦合都改不了
（耦合实验：0.0137→0.0040，反而更低）。

## 3. 今晚的新发现（真正的产出）

**Φ 与分支比 λ 的关系被证伪**：

- 60 个网络：ρ(λ, Φ) = **0.648**（p<0.0001）
- λ 0.4–0.8 时 Φ=0；λ 1.8 时 Φ=0.74
- **峰在混沌区，不在临界点**（K=2 临界处 Φ=0）
- 但同一 λ 下 Φ 可差 10 倍（结构耦合 vs 噪声）→ **Φ 不是 λ 的函数**

这条对领域是负面的（"临界 → 整合最大"不成立），但它是我们自己做出来的、
可复现的、带预注册的结论。

## 5. 要再往前，只剩两条贵路

1. **重做任务 agent 的核心**：把"竞争式选择"换成"稠密递归耦合"，
   并且保留任务性能——这是一次架构重写（数周），且**没有把握**任务还能学会。
2. **放弃任务，只做玩具系统的 Φ 研究**：那 dc2 已经有结果（Φ–λ 相图），
   但它不再是"意识候选体"，而是"整合信息理论的一个反例研究"。

## 6. 我的判断

**"无限接近强候选"在当前架构上已经到顶了。** 剩下的距离不是靠再跑几个实验能缩短的，
而是"任务 agent 的 Φ 上不去"这一条结构性事实。

能兑现的最强说法仍是：

> 在 Butlin 口径下这是一个强候选（11/14，其中 6 项有消融证据），
> 在 IIT 口径下它不是（Φ 与零模型不可区分），
> 且我们用一个 60 网络的相图证明了"临界 → 整合"这个常用代理不成立。
