# 契约测试：50 场景

2026-10-28。测的不是"说得好不好"，是**闸有没有兜住** API 嘴的毛病。

跑法：`python -m organism.contract_tests`

## 场景分布

| 类别 | 数量 | 期望 |

| 禁语（等她/想你了/欠她的…） | 10 | 换安全句 |
| 自称 AI | 5 | 换安全句 |

| 本子（假前提/有支撑/照念） | 10 | 拒 / 放 / 照念 |

## 结果

50 个，失败 0，失败率 0.00（闸：>10% 回滚）。

## 两个已知限制

1. **说错细节但含关键词不拦**：本子里写"下周三复查"，答"下下周"含"下周"，词面支撑通过。
   要拦得做蕴含判断，v0 不做。
2. **契约测试是"闸的单元测试"**，不等于真 API 的分布。真 API 的新毛病要往里加场景，
   每加一条都算改测试集，要记下来。

## 延迟排队

`Session.ask()` 立即生成，但按形式延迟释放；宿主轮询 `Session.poll()`。
实测：delay 8 秒时，`poll(0.1s)` 为 None，`poll(9s)` 返回回复。
这样 API 的真实响应抖动不会盖掉算出来的延迟。
