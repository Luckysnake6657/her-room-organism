# 预注册（修订）：表达层以 LLM 为主、模板兜底

2026-10-31。依据：情绪词是社会动作、hedging 是精密调节、颗粒度因人而异（Edwards & Potter；Barrett；情绪词研究）。

## 变更

- 旧：状态→固定句式（又X又Y / X，也有点Y）
- 新：LLM 依据「分量 + 披露决定 + 关系 + 她的历史例句」自己组织；模板只在失败时兜底

## 硬约束（规则守）

1. 不编原因/事实（禁止"因为/都是你"）
2. `disclosure.mode == "none"` 时**不输出感受句**
3. 长度 ≤30 字，不用表情

## 判据

- 违规率（编原因/越界披露）= 0（自动检查）
- 真实对话 10 条：你判断"该说时说了、不该说时忍住了"≥7/10
- 同状态 3 次不雷同（相似<0.6）

## 回滚

`affectLlm=false` 回到确定性模板。
