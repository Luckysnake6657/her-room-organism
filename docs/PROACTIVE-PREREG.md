# 预注册：主动开口（多理由 + 可用性 − 打扰成本）

2026-10-31。目标：让她"活"起来，主动但不烦人。

## 文献

- Proactive Conversational AI 综述（NSF 10580599）：触发→时机→内容
- Human-centered Proactive Agents（arXiv 2404.12670）：打扰成本
- Social presence & individual differences（Wiley cb.70207）
- ComPeer（CSCW 2024）：主动消息的接受与反感
- Horvitz 1999：混合主动的期望效用

## 理由分（先验）

| 理由 | 分值 |
|---|---|
| 共享情境（摄像头看到他在） | +0.25 |
| 关系维护（>8h 没聊 +0.25，>24h +0.35） | |
| 互惠（她问过没被回） | +0.30 |
| 情绪（孤独>0.6 +0.20；精力高 +0.10） | |
| 时机（0–6 点 −0.40；23 点后 −0.20） | |
| 可用性（摄像头看到 +0.20；键鼠活跃 +0.10） | |
| 打扰成本 | −0.25 |

决定：`理由和 + 可用性 − 成本 > 0.35` 且私聊、非忙时才开口；群里默认不说。

## 判据（一周）

- 主动消息接受率（他回了）= ≥30%
- 被嫌烦/无视率 ≤10%
- 夜里（0–6）主动 = 0
