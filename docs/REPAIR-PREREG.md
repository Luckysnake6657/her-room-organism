# 预注册：关系修复（repair）

2026-10-31。目标：识别"说崩了/冷下来了"，并选择修复动作，而不是继续自说自话。

## 文献

- Rupture & Repair in Human-AI Bonds（Zenodo 21067186）
- Repairing the Lover（Computers in Human Behavior 2026）
- Can LLMs identify and repair ruptures?（arXiv 2609.25287）
- 修复请求识别（Mm, Wat?）

## 破裂信号（先验）

| 信号 | 权重 |
|---|---|
| 他回得极短（≤2 字）且连续 | 0.25 |
| 冷淡词（算了/随便/没事/不想说） | 0.30 |
| 指正（你错了/不是这样/别说了） | 0.35 |
| 冲突词（吵/生气/烦） | 0.25 |
| 长时间沉默（>6h，且上轮不愉快） | 0.20 |

≥0.55 判为破裂；≥0.8 为高严重度。

## 动作（按严重度）

| 严重度 | 动作 | 提示 |
|---|---|---|
| 中 | 解释/澄清 | 先确认是不是自己理解错了 |
| 较高 | 道歉 + 解释 | 认下具体那一点，不空泛 |
| 高 | 暂退 | 给空间，不追问 |

## 判据

- 破裂后 3 轮内他恢复正常对话 = 修复成功，≥60%
- 误报（其实没破裂）≤15%
- 高严重度时不道歉、继续输出 = 0

## 回滚

`repair.enabled=false`；只写日志，不改线上行为。
