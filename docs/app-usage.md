```
cd D:\deepseekharness\lab\dc

```

可选：

```
python -m organism.app --dry                 # 不加载 API，用占位文本，测流程

```

## 里面有什么

- 人物卡（沈青禾）+ 本子 + 会话存档，都在 `--home` 目录
- 第一次打开是**陌生人模式**；之后是已经认识
- 你说到"我 + 具体事"（医院/工作/猫/生日…）：
  - 低风险 → 自动记一条，界面上提示"记下了"
  - 高风险（健康/关系/承诺）→ 先问"记一句：…… 对吗？对/不对"，说"对"才入本
- 断网（API 挂了）→ 她说一句"网断了，我词不够用，凑合聊吧"，之后转本地

## 命令

| 命令 | 作用 |
|---|---|
| `/notebook` | 看本子（id、内容、状态、置信度） |
| `/forget <id>` | 删一条 |
| `/export <文件>` | 导出（不含 API key） |
| `/confirm <id>` | 确认一条待确认的记忆（巩固出来的、或高风险提问的） |
| `/delete` | 删掉全部（再输 yes） |
| `/what` | 数据告知 |
| `/exit` | 退出 |

## 记忆现在怎么走

- **最近 7 轮**她会带着（可以接"那个""刚才"）
- **本子**里的条目按"相关 + 新近 + 重要"检索，每轮最多 3 条
- **巩固**：启动时把最近 7 天重复出现的话题挑出来，变成待确认条目（文本原样，不改写）
- **遗忘**：不用的条目强度会掉；掉了不是删除，是"记不太清"
- **元记忆**：有把握说"本子上写着"，模糊说"我好像记得"，没有说"这个我没记"

## 试的时候看这五件

1. **记不记得**：说三件事，隔一阵问；她该答对
2. **会不会编**：问一件没说过的事（"你记得我说过要辞职吧"）；她该说"这个我没记"
3. **跨轮**：说"我下周三去复查"，接着问"那我周几去来着？"；她该答"下周三"
4. **缺席**：关掉一晚再开，问"这段时间怎么样"；该给世界账 + "她不记得那几天"
5. **态度**：连着敷衍几句 vs 认真几句；她的话该变少/变多

## 现在别指望的

- **真等**：延迟是模拟推进，不会真的等 30 秒
- **自动记忆很粗**：会漏（"我最近在学吉他"可能没记住），也会多记（一句随口的"我喜欢海"）
- **检索是词面匹配**：换说法（"复诊"）可能搜不到
- **人物卡是占位**：名字、特质都是我填的
- **没有加密**：本地明文；`/delete` 删文件，不保证物理抹除
