## 一、时间线

### 阶段 1（上午）：测量链条，从"本地模型能不能当仪器"开始

| 做了什么 | 结果 |
|---|---|
| 本地 1.5B 的 JSON + 动作熵闸门 | 严格 JSON → 动作塌成"答"（熵 0）；改**约束解码**后熵 1.16 bit |
| 线性探针（四种状态能否被解码） | 三次失败：泄漏 → 索引错位 → 修好后 **LOSO 0.573** |
| 扩样本到 192 | 消息留出 **0.569**，CI [0.524, 0.615]，置换 p=0.005 |

**副产品**：抓出"仪器要配已知阳性自检"这条纪律——靠它才发现索引错位。

### 阶段 2（中午）：CAA 阳性对照，判据改了三次

| 轮次 | 判据 | 结果 |
|---|---|---|
| 8 样本 JS | 3× 地板 | 0.656 < 0.703，否 |
| 24 样本 JS | 置换 | p=0.42，否 |
| 24 样本均值 | 非配对置换 | p=0.007 > 0.002，否 |
| 合成对照 | 配对 vs 非配对 | 0.0004 vs 0.20 → **问题在检验设计** |
| **配对确认** | 单元内置换 | **层 12 p=0.0007、层 16 p=0.0019，通过** |

**结论**：CAA 在中间层有效，是**层局部**效应。**同一个效应被不合规的检验否决了三次。**

### 阶段 3（下午）：软提示对齐探针

| 项 | 结果 |
|---|---|
| 表征对齐（留出消息） | 1.000，余量 0.424 |
| 行为 | **0/4**（1 退化、1 人格崩塌、2 无效应） |
| 三种机制假设 | 分布外/冲过头/空洞——**全被数据否定** |
| 剩余解释 | **欠定**：单点单层单 token 的标量对齐约束不了路径 |

### 阶段 4（傍晚）：框架的地基塌了一次

发现一个内部矛盾：**用 IIT 的 Φ 当证据 + 用功能主义当许可证**，两者互斥。
解法不是三选一，是**声明框架 + 分开报告**：
功能主义框架下评 14 项（主判据），Φ 作为"模型的整合度"独立报告。

**Butlin 14 项真实评估：met 0 / partial 4 / absent 10**，且 **Φ 根本不在那 14 项里**（原文排除 IIT）。

### 阶段 5（晚上）：QQ 接通了，又停了

- 接通：NapCat + 本地服务 + 白名单消费者，**1.4 秒往返**，U4 通过
- 生产桥接**零改动**（试过的转发分支已回滚）
- 停了：按"内部系统主导"的标准，这条路线不成立

### 阶段 6（当晚）：方向推翻重来

**核心认识**：架构倒置了。本该"内部系统主导、LLM 只是嘴"，做成了"LLM 是脑、内部状态是音量旋钮"。

**新方向**：做出**一个自己**——
- 机体（不是核）：六系统、七条时间尺度、耦合
- **人类生理**（唯一自带解码器的生物）
- 效价来自对身体变量的推断，不是写死的常数
- **谎话在词里，实话在形式上**（形式由机体控制）
- 产品不死；科研保留死亡对照

## 四、这一天真正学到的东西

### 方法层（最值钱）

1. **仪器要配已知阳性自检** —— 靠它抓出索引错位
2. **配对检验** —— 不合规的检验能把真效应否决三次
3. **判据里每个数必须同口径** —— 地板用 24 样本、效应用 8 样本，比的是两回事
4. **小样本下"不可分"和"可分"都不可信** —— 0.333 → 0.667

### 认识层

5. **表征对齐不是行为对齐的充分条件**（0/4，且三种机制假设全被否定）
6. **单点标量对齐是欠定的**（同对齐、不同行为）
7. **Φ 不在 Butlin 14 项里**，拿它当候选证据是范畴错误
8. **让人在意和让人上瘾是同一套工程手段** —— 分界线在归因，不在强度

### 架构层

9. **接口位置决定权力归属** —— 状态只能变成文字进去，就永远是顾问
10. **权力该放在"做什么"，不是"说什么"** —— 而"做什么"不需要语言
