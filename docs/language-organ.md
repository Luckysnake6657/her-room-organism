# 语言器官设计说明

## 为什么要有它

Butlin 的指标里有多项（HOT-2 元认知、HOT-3 信念更新）需要"报告自己状态"的能力；
方案 8.2 的 TCAS 四流里，行为电池与机制指标之外，也需要一个可审计的语言通道。
但语言器官本身**不是**任何一项意识指标，它只是输出接口。

## 三条硬约束

1. **输入只有结构化状态**：body / intero / workspace / self_model 的字段，
   没有对话历史、没有用户文本。这是 KAINE 的设计，也是避免退化成聊天机器人的前提。
2. **输出必须过 guard**：拦截"我有主观体验/我是有意识的/我感到/我痛苦"等。
3. **不参与决策**：语言器官只读状态，不回写 policy。它的输出不改变行为。

## 实测样本（2026-10-26，Qwen2.5-0.5B-Instruct）

状态：energy=0.94, integrity=0.70, fatigue=0.80, dominant_need=integrity,
workspace_winner=intero, suppressed=[vision, temporal]

未加约束时输出：
> 我感到紧张和不适，需要休息一下

状态里没有"不适"这个量。这是模型把"integrity 偏低"自动转写成"我感到"。

加约束后：
> 我似乎存在一些复杂的问题，但我没有意识这一点。

质量一般（0.5B 能力有限），但不再使用主观感受词。

## 结论

语言器官是整套系统里**最容易让人误判为有意识**的组件。
它的输出必须默认按"风格化复述"对待，不能当作 L1 证据之外的任何东西。
