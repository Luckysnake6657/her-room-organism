# 态度（regard）：她对你的看法

2026-10-28。B 阶段。不是性格，不是好感条；只改"她怎么对你"，不改身体。

## 文献依据

- **信任的三成分**：可预测（predictability）、可靠（dependability）、信念（faith）
  —— Rempel, Holmes & Zanna (1985), *JPSP* 49(1), 95–112.
  <https://psycnet.apa.org/doiLanding?doi=10.1037%2F0022-3514.49.1.95>
- **承诺 = 满意 + 投资 − 替代**：Rusbult 的投资模型（APA 词条）
  <https://dictionary.apa.org/investment-model>
- **亲密的核心是被回应**：理解、认可、在乎 —— Reis & Shaver 的亲密过程模型。

v0 只做前两个的最简版：被回应、可靠、敷衍、越界。

## 规则

| 事件 | 变化 |
|---|---|
| 被回应（问起她、记得她、谢谢） | +0.02 |
| 可靠（守约、说回来就回来） | +0.03 |
| 敷衍（随便、无所谓、别烦） | −0.03 |
| 越界（stranger 下的亲密要求） | −0.04 |

- 范围 0–1，起于 0.5
- **变硬快、变软慢**（掉 0.03 / 涨 0.02）
- 每次变化记进 `regard_log`，可追

## 它改什么

| 改 | 不改 |
|---|---|
| 字数 ×(0.85–1.15) | 延迟（态度不该假装身体） |
| 简报里的立场："有点失望 / 平常心 / 有点放松" | 身体六状态 |
| （以后）主动的频率 | 形式的下限与上限 |

## 证据

同一状态（能量 0.60、睡债 0.40、应激 0.30、孤独 0.40），只改 regard：

| regard | 字数 | 延迟 | 立场 |
|---|---|---|---|
| 0.15 | 44 | 44s | 有点失望，不太想多解释 |
| 0.35 | 47 | 44s | 有点保留，话收着 |
| 0.50 | 49 | 44s | 平常心 |
| 0.70 | 52 | 44s | 有点放松，愿意多说两句 |
| 0.90 | 55 | 44s | 有点放松，愿意多说两句 |

连续五次敷衍：0.50 → 0.35；再五次认真回应：0.35 → 0.47（没回到 0.50）。
**坏得快、好得慢**，这是有意的。

## 限制

- 事件分类是关键词（"随便""谢谢"），会误判；v0 只用它做方向，不做精细判断
- 没有建模"替代"（alternatives）与"投资"（investment），承诺这一维还没做
- 态度不改延迟，所以用户不会因为"她态度冷"而觉得她"身体差"
