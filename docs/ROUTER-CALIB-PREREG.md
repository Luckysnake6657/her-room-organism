# 预注册：分流修复 + 校准器重训（2026-10-30）

## 一、分流（"在吗"误查记忆）

### 假设
H1：在 `memory_router` 里补寒暄表 + 短句规则后，寒暄不查记忆，且不误杀记忆问句。

### 数据
- 从 `cmw_messages` 抽 20 条真实寒暄（在吗/嗯/早安…）
- 抽 20 条真实记忆问句（记得/上次/我说过…）
- 两组互斥

### 判据
- 寒暄跳过率 ≥ 90%
- 记忆问句跳过率 ≤ 5%
- 不达标就回退规则

### 控制
- 对照组：现行分流规则跑同一批
- 改完跑 `test_invariants` 55 组

## 二、校准器（p_cal 偏低）

### 根因假设
H2：校准器训练用的是字面检索特征，线上走重排分数（尺度不同），导致分布偏移。

### 做法
1. 用**重排路径**重新生成 ablation 数据（50 次对半拆）
2. 特征同前（score/margin/n/coverage/长度/来源），但 score 用重排后分数
3. logistic + 按问题分组 5 折
4. 输出裁剪 [0.05, 0.95]

### 判据
- AUC ≥ 0.75
- ECE ≤ 0.10
- 对照组：打乱标签 AUC ≈ 0.5
- 和旧校准器比，ECE 至少降 30%

### 上线方式
- 先影子一周：只记 p，不改 band
- 一周后看 p 与实际对错的一致性，再决定是否切

## 三、回滚
- 分流：保留旧 router 文件备份
- 校准：`--no-calib` 即回退
