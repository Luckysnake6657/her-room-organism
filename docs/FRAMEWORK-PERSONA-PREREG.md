# 预注册：把她从提示词搬进框架（P0–P3）

2026-10-30。目标：人格/风格/意图归框架，LLM 只负责措辞。

## 文献锚点

- 角色一致性三层：知识/风格/行为（arXiv 2407.11484）
- 文体计量：句长、标点、功能词是稳定作者特征（PLoS ONE 2025）
- 跨轮一致比单句像更重要（arXiv 2610.04379）
- 风格应条件生成，不用形容词提示（IEEE 11352752）

## P0 已完成：风格画像

从 `her_lines.jsonl`（n=5105）统计，见 `evidence/p3/style_profile.json`：

| 指标 | 值 |
|---|---|
| 句长 均值/中位/p90 | 18.2 / 13 / 34 |
| 短句（≤6字）率 | 18.6% |
| 提问率 | **1.4%** |
| 表情率 | **0.0%** |

**推论**：提示词里任何"多问、用表情"的指令都与她的历史相反。

## 假设

- **H1**：最小提示词（意图 + 3 条原话样例 + 风格约束）生成的结果，比她历史分布更接近，优于现行长提示词。
- **H2**：盲读 30 条，新版"像她"≥60%。
- **H3**：同一状态重复 5 次，句长/用词不雷同（不复读）。
- **H4**：换一个 LLM，H1 指标不崩（她仍是框架）。

## 方法

1. 取 30 个真实语境（消息 + 身体状态 + 相关记忆）
2. 渲染器 A：现行提示词（基线）
3. 渲染器 B：意图 + 3 条她自己的原话 + 风格约束；无人格散文
4. **影子生成，不发送**
5. 你盲读 A/B（顺序随机），选更像她的
6. 计算 B 输出与她历史的风格分布 JS 散度

## 判据

- JS ≤ 0.10（句长/标点/语气词）
- 盲选 B ≥ 60%
- 重复 5 次相似度 < 0.6
- 换模型后 JS 变化 ≤ 0.05

不达标不切换；保留 `persona.mode` 回滚。

## 排除

- 机器人/系统消息、纯链接、字数 <2 的行
- 训练/实验脚本产生的话不算她的历史

## 修订（2026-10-30，盲测后）

第一轮盲测（10 对）因测试 bug（状态写死"有点累"）作废。

第三轮（10 对，状态各异）结果：**B 胜 6/10 = 60%**，95% Wilson 区间 [31.3%, 83.2%]。

**结论：压线，不作为切换依据**（n=10 区间过宽）。
追加复测：**20 对、新语境、同方法**，判据不变（B ≥60%）。
若 20 对结果 ≥60% 且区间下界 >50%，才进入影子切换；否则记为阴性。

### 追加（第五轮后）

第五轮（B 限 24 字，20 对）结果：13/20 = 65%，区间 [43.3%, 81.9%]，**下界 <50%，不切**。

按预案再跑第六轮（新语境 20 对，同 B），与第五轮合并 40 对：
- 合并胜率 ≥60% 且区间下界 >50% → 切换
- 否则 → 阴性，保留旧提示词

### 最终结果（阴性）

- 第五轮：13/20 = 65%
- 第六轮：8/20 = 40%
- **合并：21/40 = 52.5%，95% 区间 [37.5%, 67.1%]**

**结论：未达标，不切换。**
"132 字最小提示词 + 她自己原话样例"在当前模型/语料下，没有打败现行提示词。
保留旧提示词；影子代码与画像保留，供以后换模型/换样例策略时复用。
