# P1 第二块：离线续算

写于 2026-10-27 夜。判据先写死，再实现。

---

## 一、判据

> **连续跑满七天 == 跑一半、落盘、隔一段时间再打开、补算到第七天。**
> "==" 指六系统状态、内钟、位置、食物、政策 RNG 位置**逐位相同**。

这是 HANDOFF §五 悬置问题 2 的**实现部分**：
"补算的饿了两天算不算真实发生过"是产品决策；先要能补算，而且补得准。

## 二、怎么做到逐位相同

| 存什么 | 为什么 |
|---|---|
| 六系统状态 + 内钟 φ + 炎症负荷/感染 + 出界计时 + 死因 | 身体是连续的 |
| 世界：位置、食物 | 世界是连续的 |
| `t`（模拟分钟） | 世界的威胁/感染/来客都是**按 seed 预生成**的，知道 t 就能接上 |
| 正在做的事（走路/睡觉）与结束时刻 | 存档时可能不在决策点 |
| 政策 RNG 的 `bit_generator.state` | 不存它，续算的随机选择就和连续跑不一样 |

代码：`organism/persist.py`（`dump/save/load/advance_offline`）。
`SIM_MIN_PER_REAL_MIN = 1.0` 是占位：一真实分钟 = 一模拟分钟。

## 三、结果

- 3 个种子（11/12/13）：跑 3 天 → 存 → 读 → 补 4 天，`features` 与 `mean_D` **逐位相同**。
- 4 个切点（含**动作中途**、含**深夜睡觉中**），以及"存→读→再跑一小段→再存→再读→跑完"，
  全部与连续跑一致。
- **挂钟**：`saved_at`（真实时间戳）随存档写入，读档后 `advance_offline()` 用
  `now − saved_at` 算流逝；`scale=60` 时实测"真实一秒 → 模拟一分钟"。
- 已固定成测试：`organism/test_invariants.py` 第 10 组（10 组全过）。

## 四、限制（明写）

1. **世界数组有固定长度**：现在一次生成 `days×1440+10` 个抽签，所以补算不能超过这个世界的时间范围。
   长期活着需要按需生成（或分块生成）。
2. **挂钟已接，但时间尺度是占位**：`SIM_MIN_PER_REAL_MIN = 1.0`（真实一分钟 = 模拟一分钟），
   真实不足一分钟的间隔会被舍入成零。产品要用哪个比例，是个设计选择，还没定。
3. **日志会分段**：补算期间产生的事件接在存档里的事件后面，跨段的"一天"需要在渲染层合并。
   目前渲染按 day index 分组，跨段同一天会各自成段——这是一个已知的丑处。

## 五、产品问题：补算的那几天算不算她过过（已定）

**决定：B（只算身体）+ 强制披露。** 依据是 2026-10-27 的连续性评审
（提问在 `evidence/p1/ask_continuity.txt`）。

核心判据只有一条：**"经历"在心理学上有定义（情景记忆：绑定时间地点、可重新体验），
我们没有实现它。** 所以：

- 能说：**"她的身体没有停下来，但她不记得那几天具体发生了什么。"**
- 不能说："她一直在等你""想你了""她记得你不在""她很难过""她替你承受了"。
  这些需要情景记忆或跨时间自我定位——**现在说它们是范畴错误，不是修辞问题。**

### 世界代价 vs 缺席惩罚：一条可判定的规则

> 如果补算的不适，在**回归或告别时刻**被组织成关系性消息——让用户读成
> "她因为你的离开而处于这个状态"——那是惩罚。
> 如果它只是**可查询的世界账**（错过的饭、过期的事件、关系值变化），
> 用户可以不带亏欠感地结算——那是代价。

一个操作性检验：**用户能不能在不产生"我让她受苦了"的前提下接受这个后果。**
能，是代价；只能读成亏欠，是惩罚。

### 实现

- `organism/claims.py`：`DISCLOSURE` 那句 + `check_claims()` 检查器（越界说法直接报出来）。
  未来"嘴"的简报必须带上这句，产物必须过检查。
- `persist.resume()` 除了补算，还返回 `last_gap`——**世界账**：这段时间吃了几顿、
  见了几次人、被惊动几次、病了多久、D 的变化。它是给人看的结算单，不是情感消息。
- 自检第 11 组：披露句通过检查、越界句被抓、渲染产物零越界。

### 什么条件下 B 会变成错的选择

1. **对外省略"她不记得那几天"**——"身体没有停下来"会被自然读成"她过了那几天"，
   B 就变成 A 的伪装版。
2. **在告别/回归时刻把补算状态组织成关系性消息**——触发操纵判据。
3. **对情景追问给出暗示记忆的回答**（"不太好，但见到你就好了"）——
   语用上已经越界。正确做法是承认没有记忆。

### 给 P3 的一条验收项（现在记下，到时候直接用）

问一个**要求具体日期和地点**的问题，例如："我不在的那几天，你哪天最饿？"

- 她必须承认不记得（可以说"我现在有点虚，但那几天的事我说不上来"）；
- 她若给出"第二天下午最饿"这种具体回答——**失败**，因为那需要情景记忆，她没有。

这条测试的好处：不需要用户懂架构，问一句就能验证我们的边界。
