# 初步可用标准（2026-10-27 预注册）

**先写判据，再跑。** 四条全过才算"能初步使用"。

| # | 判据 | 怎么验 | 门槛 |
|---|---|---|---|
| **U1** | 内部一致性 | `selfcheck.py` | **全部通过**（当前 85 项） |
| **U2** | 长时间行为不塌 | `soak.py` 24 小时时间压缩，12 检查点 | **0 违规**，六条不变量 I1–I6 全过 |
| **U3** | 数据边界可用 | 知情闸门 / 导出 / 清除 | 三项都按预期工作 |
| **U4** | 真实对话走得通 | 真发一条消息，走外部 API | 有回复、无报错、状态与台账正确落盘 |

**U1–U3 不需要 API，今天可跑。U4 需要用户先跑一次 `--i-consent`。**

## 不算"可用"的情况（写死，防止事后放宽）

- 任何一项 selfcheck 失败
- soak 出现任意一次不变量违规
- 知情闸门可被绕过、导出缺文件、清除留残
- 真实对话报错，或回复落盘与状态不一致

## 明确不在本次范围

- 第 7 条「她会变」（架构上无慢参数，另案）
- 多人/长期使用（没有数据）
- 用户研究（"像不像"没测过）
