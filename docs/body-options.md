# 身体要件对照：MuMu vs 笔记本本体 vs ESP32

| 身体要件 | MuMu 模拟器 | 笔记本本体 | ESP32 |
|---|---|---|---|
| 内感受（自身真实状态恶化） | ✗ 虚拟电池/温度，可随意改 | ✓ CPU/GPU 温度、负载、电池消耗 | △ 仅电压/温度，无"能力被削弱"语义 |
| 外感受·视觉 | ✓ 屏幕截图（1080p，丰富） | ✓ 摄像头（真实房间） | ✗ |
| 外感受·听觉 | ✗ | ✓ 麦克风（真实声波） | ✗ 仅蜂鸣器反馈 |
| 输出·改变世界 | ✓ 点击/滑动/输入（应用内） | ✓ 扬声器（真实声波）+ 屏幕 | ✓ 蜂鸣器/马达 |
| 世界极（独立于系统） | △ 仅当对端是真人（QQ） | ✓ 房间、声音、他人 | △ 物理但极窄 |
| 物理因果不可逆 | ✗ 快照可回滚 | ✓ | ✓ |
| 扰动可控性 | ✓✓ 虚拟传感器/GPS/网络/电量 | ✗ | △ |
| 社交对端 | ✓ 可装 QQ 接真人 | ✗ | ✗ |

## 判定

- **MuMu = 眼睛 + 手 + 社交出口 + 扰动台**，不是身体。
- **身体 = 笔记本本体**（内感受真实、世界极独立、因果不可逆）。
- 两者叠加，才覆盖方案 4.1「变量恶化直接削弱系统自身控制能力」这条核心设计——MuMu 的虚拟电池做不到这一点，因为它是可设的常数。

## 对 Butlin 指标的影响

| 指标族 | 只用 MuMu | 笔记本 + MuMu |
|---|---|---|
| embodiment / agency | L1（架构声明） | L3（有真实输出→传感器回路） |
| 内感受相关 | 不可评 | L3–L4（可消融真实遥测通道） |
| 世界极（TRO W） | 退化为 dyadic | 成立（房间 + 真人 QQ 对端） |

结论：MuMu 不替代身体，它把"世界极"从"无"补到"社会性存在"，并提供一个 ESP32 给不了的扰动台。
