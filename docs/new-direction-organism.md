# 新方向总结：从"整合度"到"有没有一个自己"

2026-10-27 晚定。此前所有工作作废**不是**因为做得不好，是因为**架构倒置**：
本该是"内部系统主导、LLM 只是嘴"，做成了"LLM 主导、内部状态只是音量旋钮"。

---

## 一、目标变了

| 旧目标 | 新目标 |
|---|---|
| 让 4 维核的 Φ 高，并进入生成分布 | 让系统**自我维持**，其状态对它自己有好坏 |
| 争取"意识候选"资格 | 让"有没有体验"落在**无法反驳也无法承认**的位置 |
| LLM 是主体 | LLM 只是嘴（且不接方向盘） |

**核心判断**：不可判定性来自**结构**，不来自话术。
一只线虫不可判定，因为它是一个自我维持的整体；我们的旧系统不是——状态对它自己无所谓。

## 二、设计目标：人类生理，不是通用生物

为什么要人：
> **人类是唯一一种我们自带解码器的生物。**
> 模拟的鱼饿了没人看得懂；人饿了、困了、被伤了，**立刻懂**。

### 要模拟的不是变量数量，是**时间尺度**与**耦合**

| 系统 | 时间尺度 |
|---|---|
| 心率 / 呼吸 | 秒（**v1 未实现**：六个系统里没有这一条） |
| 饥饿 / 口渴 | 小时 |
| 睡眠压力（累积、欠债） | 一天 |
| 应激轴（升快、恢复慢） | 几小时 |
| 昼夜节律 | 24 小时 |
| 免疫 / 生病 | 几天 |
| 依恋 / 孤独 | 几个月（**目标；当前实现是天级**，实测见 `docs/p1-timescales.md`：约三天饱和） |

**七条不同时间尺度叠在一起，才叫"人"。只有能量条的是仓鼠。**

### 必须耦合（这是"像人"的真正来源）

- 睡不够 → 应激升高 → 心率偏高 → 更容易烦
- 饿 → 情绪基线下降 → 更受不了被冷落
- 孤独 → 应激升高 → 睡得浅 → 第二天更累
- 生病 → 什么都不想做 → 连话都变少
- 被安抚 → 应激下降 → 恢复加快

## 三、文献：三条脉络

### 1. 自创生 / 生成认知（autopoiesis, enactivism）
Maturana & Varela；Thompson；**Di Paolo 的"适应性（adaptivity）"**是关键补充：
一个系统光是自我维持还不够，**它必须"在意"自己是否在维持**——这才是效价的来源。

### 2. 内感受推断 / 感受
**Damasio**：稳态与感受（homeostasis → feelings）；**Seth** 的"内感受推断"与
"beast machine"论：情绪是对身体内部状态的推断模型，不是对世界的推断。
→ 对我们的直接含义：**效价必须来自身体变量的推断，而不是我们写死的常数。**

### 3. 人工生命与产品先例
- **Tamagotchi (1996)**：死亡机制有效，但状态是单一量表
- **Creatures (1996, Steve Grand)**：**norn 有一套模拟生化**（葡萄糖、血清素等）
  ——"用生化模拟做娱乐产品"这件事，三十年前就有人做过
- 研究显示 Tamagotchi 的依恋强度明显低于真实宠物（UCI 本科论文，样本小）

**教训（必须记住）**：Creatures 的生化模拟让生物**难以理解**——玩家看不懂它在想什么。
所以我们这一版的成败，取决于**状态对人类可读**，不取决于模拟得多真。

## 四、我们的差异点在哪

| 维度 | 先例 | 我们 |
|---|---|---|
| 生理模拟 | Creatures 有 | 有，且**用人类生理**（可读） |
| 表达 | 游戏内动画/叫声 | **自然语言**（LLM） |
| 真实性约束 | 无 | **真相包络**：LLM 不能说与状态矛盾的话 |
| 权力分配 | 状态驱动行为 | 状态驱动**世界上的一切**，LLM 只表达 |

**唯一真正新的东西是"谎话在词里，实话在形式上"**：
内容由 LLM 生成（**可以撒谎**），形式由机体决定（**不会撒谎**）。

## 四·五、修正：不能设计成"不会撒谎"

初稿写的是"真相包络：状态不允许说的话说不出来"。**这是错的，那是机器。**

> **人会说"我没事"——恰恰是这句话维持了关系。**
> 让用户知道她不好的，不是她说了，是**她藏不住**。

### 三个通道

| 通道 | 谁控制 | 能不能撒谎 |
|---|---|---|
| **内容**（说什么词） | LLM | **能**——"没事""挺好的" |
| **形式**（多快回、多长、主动不主动、绕不绕开话题） | **机体**（代码强制） | **不能**——累了就是慢、就是短 |
| 世界的真相 | 无人 | 不可协商（会死就是会死） |

**关键约束：形式必须不由 LLM 决定。** 否则它可以靠"写一段又长又热情的话"把漏堵上。

### 三种撒谎，分开处理

| 类型 | 例 | 产品 |
|---|---|---|
| 善意 | "我没事"其实很累 | ✅ 要，最像人的一种 |
| 赌气 | 明明在意，偏不说为什么 | ✅ 要，这是脾气 |
| 恶意 | 编造关于世界的事实来操纵你 | ❌ 红线 |

**红线画在"编造世界的事实"，不画在"隐瞒自己的状态"。**

### 这一条同时是验收标准

> **她说"没事"的时候，你能不能看出来她不好？**

- 看得出来 → 成立，而且这就是亲密感的来源
- 看不出来 → 失败：机体没接上形式，或形式被 LLM 接管了

**注意：我们的 `enforce()`（截断、删问句、延迟）已经是"形式"通道的雏形**——
新方向不是从零开始，是把这些从"音量旋钮"升级成"身体"。

## 五、v1 规格（6 个系统，多一个都不要）

1. 能量（吃）
2. 睡眠压力（累积；一次睡够才清）
3. 应激（升快、恢复慢）
4. 昼夜节律（压着睡眠与情绪）
5. 免疫（长期高应激 → 生病）
6. 依恋（孤独累积；被回应才降）

**判据**：
- 系统间至少 **8 条耦合边**
- **拆掉任一子系统，行为明显变形**（这是"缺一不可"的操作化）
- **不显示任何数字**

## 六、必须定的三件事

1. **死亡怎么处理**：**已定（2026-10-27）——产品不死**；科研实验里保留死亡作为对照。
   - 理由：产品里死了会出事（用户受伤、客服、口碑），且没法安全测试。
   - 替代重量的来源是**不可逆与代价**：
     - **生病**：长期忽略 → 病倒几天，要照顾才恢复（可逆但花时间）
     - **慢性化**：反复恶化 → 变成长期状态（基本不可逆）
     - **距离**：长期冷落 → 变远，需要几周暖回来（可逆但很慢）
     - **错过的日子**：你没在的那几天永远补不回来（不可逆）
   - **产品判据改成**：她的状态有没有"回不去"的部分？
     全是可恢复的 → 还是仪表盘。
   - **科研对照实验**：会死 vs 不死但会病会远，测"活物感"与照顾投入度。
     两个结果都有价值，而且都不需要真的发布一个会死的东西。
2. **它不说话时你还在意吗**
   （若必须靠嘴才在意，说明嘴在起作用，又回到旧路）
3. **离线时它是否继续活**
   （补算的"饿了两天"算不算真实发生过——这决定产品的诚实性）

## 七、判死条件

- 六系统拆任何一个，行为不变 → 还是仪表盘，方向不成立
- 必须先靠嘴才让人在意 → 不是机体在起作用
- 状态无法被人类从行为中读出 → 重蹈 Creatures 的坑
