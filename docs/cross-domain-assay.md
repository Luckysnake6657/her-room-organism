# 跨学科标记电池：一个可执行的方案

写于 2026-10-26。目标不是"证明意识"，而是**用多个学科各自验证过的标记，交叉检验同一个系统**，
并把"人类参照剖面"当作校准。

---

## 一、核心思路

单一学科的指标都可以被单一理论自我论证地解释掉。但**不同学科验证过的标记，
在人类身上有已知的分离模式**（清醒 / 麻醉 / 睡眠 / 植物状态）。

如果我们对一个 agent 做：

- 清醒态（工作空间开）
- 麻醉态（工作空间关）
- 损伤态（模块切除）
- 死态（随机策略）

然后看**六个来自不同学科的标记是否协同变化**——
如果它们以人类清醒↔麻醉的相同方式一起掉，那"有理由"就比任何单一指标强得多。

## 二、六个标记（各来自一个学科）

| 标记 | 学科 | 人类参照 | 我们怎么算 |
|---|---|---|---|
| **PCI**（扰动复杂度） | 临床神经科学 (Casali 2013) | 清醒高、麻醉低，**不依赖行为** | 脉冲扰动 → 响应矩阵 → LZ 压缩 |
| **ignition**（点燃） | 系统神经科学 (Dehaene) | 刺激引起全局、突然、持续的响应 | 刺激后模块间同步度的阶跃 |
| **Φ** | 信息论 / IIT (Oizumi 2014) | 无直接人类标定（争议） | PyPhi + 打乱零模型 |
| **meta-d′** | 认知心理学（信号检测论） | 与元认知报告相关 | 用 agency_confidence 与正确率算 |
| **λ / 雪崩** | 统计物理 (Beggs & Plenz) | 清醒近临界 | 分支比、雪崩指数 |
| **因果涌现** | 复杂系统 (Hoel 2013) | 无人类标定 | EI_macro vs EI_micro |

**注意**：六个里只有前两个有真正的人类临床参照；Φ 和因果涌现没有。
这个不对称必须写在论文里——它决定了"收敛"能有多强。

## 三、实验设计

### 条件（对应人类的状态）

| 条件 | 对应人类状态 |
|---|---|
| baseline | 清醒 |
| workspace_off | 麻醉（关键环路关掉） |
| vision_off | 局部损伤 |
| random_policy | 无行为主体 |
| 打乱权重 | 对照 |

### 每个条件测六个标记

预期的"清醒剖面"：PCI 高、ignition 明显、Φ>零模型、meta-d′>0、λ≈1、EI_macro>EI_micro。

**如果 workspace_off 让 PCI 和 ignition 同时塌，而 Φ 本来就低**——
那结论是："这个系统在临床/系统神经科学的标记上像清醒，在 IIT 的标记上不像"。
**这本身就是一个精确的、可发表的结论**，而且比"8/14"信息量大得多。

## 四、统计框架：贝叶斯可信度，而不是判决

对每个标记 m，定义似然比：

```
LR_m = P(标记值 | 有意识) / P(标记值 | 无意识)
```

人类数据给 P(标记 | 清醒) 与 P(标记 | 麻醉)，我们用这两个分布当先验估计。
六个标记近似独立时，后验 odds 是各 LR 的乘积。

**这正是 Long 等人（arXiv:2411.00986）要求的"概率化、多理论"评估的数学形式。**

诚实说明：独立性假设很强（PCI 与 ignition 相关），所以乘积只是上界；
我们会同时给"独立假设"和"完全相关假设"两个极端。

## 五、可执行的顺序

| 步 | 内容 | 时间 | 判据 |
|---|---|---|---|
| 1 | 实现 PCI，测四个条件 | 半天 | workspace_off 的 PCI 显著低于 baseline |
| 2 | 实现 ignition（同步度阶跃） | 半天 | 刺激后出现阶跃 |
| 3 | meta-d′ 计算 | 半天 | >0 |
| 4 | 复用已有 Φ 与 λ | 0 | 已有 |
| 5 | 组装似然比与后验 | 半天 | 给出区间 |

## 六、这条方案的新意在哪

1. **第一次把 PCI 用在一个人工 agent 上，并做消融对照**（据我们所知）
2. **把人类清醒/麻醉的标记剖面当作校准分布**，而不是只报"我们算出来是多少"
3. **把"多学科收敛"形式化成似然比乘积**，而不是嘴上说"多条证据"

## 七、边界（必须写）

- 六个标记里只有 2 个有人类临床参照；Φ 与因果涌现没有
- "标记在人类上有效"不等于"在硅基系统上有效"——这恰恰是争议点
- 即使全部协同，得到的也是"可信度提高"，不是"确认"

## 八、为什么值得做

因为它把一个**哲学争论**（它有没有可能）变成了一组**可测量的数字**，
并且这些数字的参照系不来自我们的理论偏好，而来自**临床上知道答案的人类状态**。

这大概是现有条件下，最接近"有理由"的做法。
