# D 阶段：校准、习惯、30 天纵向

2026-10-28。三件：conformal 校准、习惯检测、30 天两臂纵向。

## 一、校准（`organism/calib.py`）

依据：
- 分箱校准与 ECE：Guo et al. (2017), *ICML*, "On Calibration of Modern Neural Networks"
- 自适应区间（ACI）：Gibbs & Candès (2021), *JMLR*, "Adaptive Conformal Inference Under Distribution Shift"
- 块均值思路：`docs/memory-confidence-gate.md`（小样本不要用块最大）

做法：把原始 confidence 按分箱均值映射到经验准确率；报三件套。

合成数据（真实准确率 = c，原始置信被高估为 √c）：

| 指标 | 值 |
|---|---|
| ECE（校准前） | 0.150 |
| ECE（校准后） | **0.052** |
| 覆盖率（θ=0.70） | 0.84 |
| 区间宽度 | 0.16 |
| WIS（本项目的变体：Brier + 0.5×宽度） | 0.245 |

**诚实说明**：这是"分箱均值"的最小 conformal，不是完整 conformal prediction；
WIS 是本项目定义的变体（Brier + 宽度惩罚），不是标准 WIS。

## 二、习惯（`organism/habits.py`）

最近 14 天、出现 ≥3 次的不同条目 → 话题。

实测：三条都提到"复查" → `[{'topic': '复查', 'count': 3}]`；只有一条 → 空。

**限制**：二字词切分很粗，会把"复查"和"查结"都算上；只用来提示"你最近常提"，
不进断言、不当记忆用。

## 三、30 天纵向（`organism/longitudinal.py`）

两臂，每天一句，同一身体状态：

| | 第 1 天 | 第 15 天 | 第 30 天 |
|---|---|---|---|
| 认真（regard / 漂移 / 字数） | 0.51 / 0.000 / 37.9 | 0.68 / +0.012 / 37.8 | **0.86 / +0.024 / 40.4** |
| 敷衍（regard / 漂移 / 字数） | 0.48 / 0.000 / 37.6 | 0.28 / −0.012 / 32.3 | **0.05 / −0.024 / 29.4** |

- 第一版打得太快（30 天顶到 0 和 1），改成**按天结算 + 幅度减半**
- 现在两臂分开、不饱和；30 天差 0.81 regard、0.048 漂移、11 个字
- 差异可追到每天那句话（regard_log / trait_log）
