# 预注册：元认知（监控 + 控制 + 消融）

2026-10-31。目标：证明元认知不是装饰，而是可测、可被反驳的机制。

## 定义

- **监控**：置信能区分自己答对/答错，且超出一阶难度（meta-d'、M-ratio）
- **控制**：置信**因果地**改变行为（不确定→反问/核实/少断言）

## 实验 1：监控（更难样本）

- 题集：准确率目标 70–80%（从现有 quiz 中筛低边际题 + 新题）
- 样本：≥200 次判断
- 指标：type-2 AUC、meta-d'、M-ratio、ECE
- 判据：meta-d' 的 95% CI 下界 >0；**M-ratio >0.5**
- 对照：打乱置信-对错 200 次，meta-d' 落在 0 附近

## 实验 2：控制（因果）

- 同一批模糊问题，随机分两种条件：
  - A：高置信提示（"你确定"）
  - B：低置信提示（"你不确定"）
- 行为指标：回复中是否出现反问/要求确认/明确说不知道
- 判据：B 组核实率比 A 组高 ≥15 个百分点（Fisher p<0.05）

## 实验 3：消融

- 关 calibrator / band，重复实验 1、2
- 判据：M-ratio 或核实率显著下降，否则该层为装饰

## 失败条件

- M-ratio ≤0.5 且打乱对照无差异 → 监控不成立
- 控制组无差异 → 控制不成立
- 两者都不成立 → 只能叫"置信度估计"，不能叫元认知

## 回滚

实验不改线上；`--calib` 关掉即回退。
