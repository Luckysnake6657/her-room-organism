# 检索定稿决定（2026-10-31）

## 结论

- **主通道**：原文 + 向量（bge-small-zh）+ cross-encoder（bge-reranker-base）
- **52 题人工语义集 top1：47/52 = 90.4%**
- 原字面 57.7%，BM25+向量 73.1%，事实+向量 84.6%
- 事实通道消融只降 3.9pp（47→45），**不承重**；当 boost 更差（88.5% vs 92.3%）

## 为什么不把事实设为主通道

证据一致指向 CE + 原文 + 向量；继续优化事实是对 52 题过拟合。
事实脚本保留（`facts*.py`），作为可选增强/未来再评。

## 为什么 CE 还没上线

- CE 约 1GB 显存；GPT-SoVITS v5 占约 7GB，8GB 卡上**共存未验证**，有 OOM 风险
- 语音是线上刚需，检索是增强；不拿语音冒险
- 待办：量化 CE / 换小模型 / GPU 升级后再评估

## 线上默认

不变：字面 + 条件重排（`--rerank-cond`）。
CE 和事实都不进默认路径；相关开关仅离线实验使用。

## 回滚

`--rerank-cond`、`--slow` 已有；CE/事实无线上开关，因为未接入。
