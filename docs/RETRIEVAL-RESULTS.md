# 检索升级结果（52 题人工语义集）

2026-10-31。预注册见 `RETRIEVAL-UPGRADE-PREREG.md`。

## 最终结果

| 配置 | 命中 |
|---|---|
| 字面（原基线） | 30/52（57.7%） |
| BM25 + 向量 RRF | 38/52（73.1%） |
| 原子事实 + 向量融合 | 44/52（84.6%） |
| **事实 + 原文 + 向量 + cross-encoder** | **47/52（90.4%）** |
| 消融：去掉事实（仅原文 + CE） | 45/52（86.5%） |
| 事实当作 boost（entry_ce + α·fact_ce） | 最优 α=0，留出 88.5%（更差） |
| 事实 v2（5 条带类型） | 37/46（80.4%） |
| 事实级 LLM 重排 | 31/43（72.1%） |

## 判据核对

| 判据 | 结果 |
|---|---|
| top1 ≥85% | ✅ 90.4% |
| 事实通道消融 ≥5pp | ❌ 3.9pp（2 条） |
| 回归 ≥75 组 | ✅ 75 |

## 结论

- **主通道是 cross-encoder + 原文 + 向量融合**，不是原子事实
- 事实通道只多救 2 条，不承重
- 把事实当 boost 反而更差（88.5% < 92.3%）

## 未接入

- CE 需 ~1GB 显存，与 GPT-SoVITS 共存未验证
- 事实索引只做离线实验，未上影子

## 建议

把目标从“事实承重”改为“检索 top1 ≥85%（原文+向量+CE）”，事实作为可选增强；
否则继续优化事实就是对着 52 题过拟合。
