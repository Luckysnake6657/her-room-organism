# P0b 预注册：应激的六条输出边，哪一条承重

冻结时间：2026-10-27（**跑数之前**）
前置：`docs/p0-prereg.md`、`docs/p0-results.md`（P0 判据 1 = 5/6，应激没过）

---

## 一、要回答什么

P0 已经知道：**把应激整个拆掉，行为只变形 1.29 倍（Bonferroni p = 0.148）**。

但"整个拆掉不变形"可能是两件完全不同的事：

- (a) 应激的六条输出边**每一条都很弱**，合起来也弱 → 应激是装饰；
- (b) 六条边**互相抵消**（比如"想找人"和"不想出门"同时被削），合起来看起来没变。

所以这次不拆系统，**逐条拆边**。这是"状态有没有接上行为"的直接检验。

## 二、设计

应激的六条输出边：

| 边 | 机制 | 位置 |
|---|---|---|
| `stress_sleep` | 应激 → 睡眠恢复变慢 | `model.step` |
| `stress_appetite` | 应激 → 胃口下降 | `policy._eat_value` |
| `stress_avoid` | 应激 → 不想出门 | `policy.options`（goto） |
| `stress_energy` | 应激 → 能耗上升 | `model.step` |
| `stress_immune` | 长期应激 → 炎症负荷 | `model.step` |
| `stress_social` | 应激 → 更想找人 | `policy._social_value` |

每条边单独关掉，其余五条保留；对照是"六条全开"（= P0 的 `baseline_c`）。

### 两个世界

| 臂 | 世界 | 理由 |
|---|---|---|
| `_c`（挑战周） | 与 P0 挑战周相同：一场统一感染 + 一场统一惊吓 | 与 P0 同口径，可直接比 |
| `_d`（密集威胁周） | 每天夜里 21:00 一场强制惊吓（共 7 场）+ 同一场感染 | 测"应激是不是只在威胁多时才管事" |

## 三、条件

每臂 9 个条件 × 24 个种子（0–23）：

`base`（六条边全开）、`null`（同模型不同噪声）、`all_off`（= 拆掉整个应激系统）、
`edge_sleep`、`edge_appetite`、`edge_avoid`、`edge_energy`、`edge_immune`、`edge_social`

## 四、判据（写死）

距离口径与 P0 完全一致：10 个行为特征、零假设 SD 归一化、配对置换。

**对每条边**（每臂单独判）：

1. 配对置换单侧 `p < 0.0083`（Bonferroni：0.05/6），**且**
2. 效应量 `d_edge / d_null ≥ 1.5`

### 结论规则（先写死）

- **某条边在任一臂里过线** → 应激"有接上行为"，承重的是这条边；后续要么保它、要么按它加粗。
- **六条边在两臂里都不过线，而 `all_off` 也不过线** → 判定 **"应激在本模型里是装饰"**；
  按 P0 结果 §七 走选项 A（砍到五系统）或 B（换世界），**不再单独调这六条边的系数**。
- **`all_off` 过线但没有任何单边过线** → 报告"交互效应"，并列出哪些特征在 `all_off` 与各单边之间不一致。
- 正对照：`all_off` 若在两臂都不过线，则本次实验的阴性**有解释力**（说明不是仪器不灵）。

## 五、控制

- `base`（六条边全开）与 P0 `baseline_c` 必须**逐位相同**（同一 seed、同一噪声）→ 检查重构没有改行为。
  重构已经用 10 次运行验证过特征逐位相等（5 个种子 × 2 周）。
- `null` 定义距离标尺；`cosmetic` 不重复（P0 已证明为 0）。

## 六、不做的事

- 不因为某条边"差一点"就改阈值或换种子。
- 不把两个臂的结果挑一个好看的报；两臂都报。
- 不在这次实验里改任何动力学参数（只关边，不改系数）。

## 七、如果结论是"装饰"

这只回答"应激有没有接上行为"，**不回答"该不该有这个系统"**。
砍掉它是产品决策；保留它是科学决策（人可以没有可测的应激反应吗？）。
两个方向都要写清楚代价。
