# 预注册：学习闭环（预测误差 → 缓慢更新）

2026-10-31。目标：让她的倾向被真实结果改变，但有上限、可审计、可回滚。

## 文献

- 主动推断：误差驱动模型更新（Friston）
- 伴侣长期演化：人格闭环（Project Sue）
- 用户建模反馈（Proactive 综述）
- 情感计算中的适应（affective computing 综述）

## 更新什么

| 参数 | 含义 | 初值 |
|---|---|---|
| expressiveness | 表达/披露倾向 | 0.50 |
| initiative | 主动开口倾向（阈值修正） | 0.50 |

## 规则

- 误差 = 结果 − 预期（结果：他是否回应/回应是否积极）
- 学习率 0.01；**单周累计变化 ≤0.02**
- 每次更新写审计日志：时间、参数、旧值、新值、误差、原因
- 跨周重置周累计；参数限制在 [0.05, 0.95]

## 判据

- 周漂移 ≤0.02（自动检查）
- 正向结果 → 参数上升；负向 → 下降
- 关闭开关后参数不变
- 回归测试 ≥70 组

## 回滚

`learning.enabled=false`；`state/learning.json` 可备份恢复。
