# O 流（LLM 代理）尝试：本机模型不可用

日期：2026-10-26
材料：`evidence/blind_packet/`（12 对，同数据、拟人 vs 机制措辞）
脚本：`run_llm_raters.py`（1–5 评分）、`run_llm_pairwise.py`（强制选择）、`run_llm_pairwise_logit.py`（logit 比法）

## 结论先说

**本机唯一能加载的模型（qwen2.5-0.5b-instruct）在这个任务上没有任何分辨力。**
它不是"测出没有措辞混淆"，而是"产不出可用的判断"。

| 方法 | 结果 | 诊断 |
|---|---|---|
| 单条 1–5 评分（24 条 × 3 次） | **全部给 3** | 常数输出，方差为 0 |
| 强制选择（12 对 × 3 次） | anthropo_win=0.5，**chose_A=0.0** | 恒选 B，纯位置偏好 |
| logit 比 A/B | meanP(A)=meanP(B)=1e-05，prefer_A=0.0 | 概率退化，全是并列 |

1.5B 模型无法加载：`OSError 1455 页面文件太小`。所以本机没有更大的可用模型。

## 怎么读

1. **不能说"没有措辞混淆"**——那需要观测者有分辨力；0.5B 连选择题都在恒选 B。
2. **位置偏好本身是个好信号**：它说明这套强制选择确实能抓到评分器偏差（只是抓到的是模型自己的），
   换个能干的评分者就有意义。
3. 用 LLM 当评分员**永远只能标注为「LLM 代理」**，不能替代 TCAS 要的人类观察者混淆控制。

## 如果要用 LLM，最低要求

1. 模型 ≥7B（0.5B 这类做不了这种判断）；本机要装更大的模型得先扩页面文件/内存
2. 或者走 API：温度 0、每对 3 次重复、A/B 顺序平衡
3. 报告两个数：**内容偏好**（拟人 vs 机制）和**位置偏好**（选 A 的比例）
4. 结论只能写"LLM 代理显示……；人类复评待做"
