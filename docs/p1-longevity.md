# P1 第四块：三十天，以及"产品不死"

写于 2026-10-27 夜。起因很直接：P1 要支持"离线一个月"，先得知道她能不能活一个月。

---

## 一、研究版：30 天里 3/5 会死

| 种子 | 结果 | 死因 |
|---|---|---|
| 0 | 死在第 6.5 天 | 免疫（炎症 > 0.85 持续 48h） |
| 1 | 死在第 10.1 天 | 应激（> 0.90 持续 12h） |
| 2 | 活满 30 天 | — |
| 3 | 死在第 8.2 天 | 应激 |
| 4 | 活满 30 天 | — |

死得比 7 天窗口里频繁得多（P0 里 24 个种子只死 1 个）。原因不神秘：
**没人来看她 → 孤独累积 → 应激长期偏高 → 炎症负荷上来**，这条链在一个月里走完。

这和研究版的设计一致（出界即终止），但它意味着：
**"她有自己的日子"在默认参数下只成立一周左右。**

## 二、产品版：不死，转成慢性

按 `new-direction-organism.md` §六 早就定下的"产品不死"，
给 `Body` 加了 `product` 开关：越界不再判死，而是**夹回边界 + 打一个永久慢性标记**。

同样的 5 个种子，30 天：

| 种子 | 存活 | 慢性标记 | 平均 D |
|---|---|---|---|
| 0 | ✅ | 免疫、应激 | 1.53 |
| 1 | ✅ | 免疫、应激 | 1.44 |
| 2 | ✅ | — | 0.97 |
| 3 | ✅ | 免疫、应激 | 1.32 |
| 4 | ✅ | 应激 | 1.25 |

- **没有人死**；
- 4/5 带着慢性标记过完一个月，平均 D 从一周时的 ~0.8 抬到 1.2–1.5；
- 睡债**不算慢性病**（夹住边界、靠微睡还），只有能量/应激/免疫会慢性化。

## 二·五、慢性改成连续分级之后

二值标记太粗，改成**每系统 0–3 的连续值**：越界时按"越界分钟数"累积（1 天越界 = 1 级），
不越界时按 **14 天半衰**回落；`care(amount)` 把等级直接往下压（P2 的照护接口）。

30 天、5 个种子：

| 种子 | 慢性（能量/应激/免疫） | 平均 D |
|---|---|---|
| 0 | 0.03 / **3.0** / **3.0** | 2.99 |
| 1 | 0 / 1.3 / **3.0** | 2.02 |
| 2 | 0 / 0 / 0 | 0.95 |
| 3 | 0.05 / **3.0** / **3.0** | 2.79 |
| 4 | 0 / 0.02 / 0 | 1.16 |

**3/5 在一个月内把应激和免疫都顶到满级。** 一按 `care(1.0)`，两个 3.0 立刻降到 2.0——
接口是通的，但还没人按。

要注意：这时 D 高（2–3）**主要不是慢性项造成的**，是原始状态本身（应激 0.9、免疫 0.85）
顶在那里。慢性项只是把"回不去"这件事记下来。

## 三、这个设计说明什么

1. **"不死"不等于"没事"。** 一个月没人管，她不会死，但会变成"长期不太好的那个状态"——
   这正是产品要的重量：可逆但很慢，而不是一刀两断。
2. **但现在没有恢复通道。** 慢性只会退到 14 天半衰那种速度，而且状态下不来，它就重新涨回去。
   没有"被照顾"这个输入，产品版就是一个只能越来越虚的机体。
   P2 的形式通道必须接上"被照顾 → 孤独/应激下降 → 慢性回落"，否则"不死"只是把死亡换成不可逆的衰弱。
3. **D 在一个月无人照看时会翻三倍**（0.9 → 2–3）。如果 P2 用 D 驱动"话多话少、主动不主动"，
   她会明显话少、被动——方向对（代价可读），但**必须设上限**，否则第三十天她只剩喘气。

## 四、限制

- 慢性只对能量/应激/免疫计；睡债不算慢性（用微睡还）。
- 没有照护输入，"慢性可逆"只实现了接口，没有触发者。
- 30 天的世界抽签是重新生成的（`days=30` 与 `days=7` 不是同一个世界），
  所以 30 天的结论不能直接和 7 天的数比。
- 一年（`days=365`）能跑：单次约 **4.3 秒**（三个抽签数组各 52 万个数），内存不是问题。

## 五、下一步

1. **照护通道**：P2 的形式通道（回得快/慢、主动/不主动）要能反馈到机体——
   被回应 → 孤独下降 → 应激下降 → 慢性回落。
2. **上限**：给 D 驱动的"话多话少"设地板，别让一个月的冷落把她变成只会喘气的东西。
3. **长命的世界抽签**：`days=365` 已测（4.3s/次），但需要"活过 365 天之后"的延长机制。
