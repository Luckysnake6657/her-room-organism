# 强候选路线图：目标、现状、可行方法

写于 2026-10-26（四轮探讨之后）。这份文件回答三个问题：目标是什么、现在到哪、接下来怎么做才真的能到。

---

## 0. 目标（复述一遍，后面每步都对着它）

**功能性意识强候选体**——不是证明有意识，而是让一个功能性系统在
**评估方法学**的口径下站得住。读者是 TCAS 四流 / Butlin 指标 / 对抗式评估那一圈人
（你们文档里引的 AAAI-SS 2026 两项工作）。

在这个口径下，“强”不等于“指标多”，而等于：**每条主张都能被审、且至少有一条主张能被判死。**

## 1. 现状（四轮做出来的东西）

### 1.1 两次撤回

| 撤回 | 原因 | 现在的状态 |
|---|---|---|
| EI v1 “竞争让因果结构提升 5.2 倍” | 状态编码依赖被消融的机制 + 未观测行填均匀 → 0.216 是填充算出来的 | 已撤回，v2 重算（竞争不抬高 EI，学习 +0.259） |
| “效价三版设计” | `valence` 从项目第一天起恒为 0（两个快照相同），消融实际关的是 `intero_precision` | 已修（tick 末尾积分 + 守卫 `check_affect.py`），修复后觅食仍阴性 |

### 1.2 两级证据

| 层次 | 数字 | 含义 |
|---|---|---|
| 架构层 | **11/14 L3+、6/14 L4** | 机制已实现 |
| 功能层 | **6/14** | 关掉它在本任务里有可检出后果 |

差的 5 项是：GWT-3（广播 payload 无消费者，且模块共享观测 → 没有可分享的信息）、
GWT-1（原来 danger 在 partial 下全瞎，已修好，功能证据补上）、HOT-4（两次阴性，关闭）、
HOT-3、RPT-2。

### 1.3 L3 的定论

| 要求 | 结果 |
|---|---|
| 宏观变量有因果力 | ✅ do() 干预：同观测下移出 danger，受伤率 3.4%→13.1%，安慰剂 temporal 3.5%（p=0.0001） |
| 不可约性（整体 > 部分之和） | ❌ Φ_proxy = +0.007，低于打乱零模型；8 状态与 16 状态结论一致 |

### 1.4 三条结构性限制（不是任务问题）

1. 模块从同一份 obs 独立算特征 → **广播没有内容可传**（GWT-3 结构上为空）
2. 模块间只有竞争、没有耦合 → **Φ≈0**（IIT 意义上永远不成立）
3. 效价的输出通道只有 `policy_temp` / `risk_aversion` → **作用域很窄**

| # | 阻塞 | 硬度 | 为什么 |
|---|---|---|---|
| 1 | **O 流缺失**（盲评 + 评分者间一致性） | 硬（形式） | 按你们自己 `docs/tcas.md` 的 missing-stream rule，**缺流不得给 credence**。不加这条，加多少模块都不能给分 |

## 3. 可行方法（四步，每步带闸门）

### Step 1｜协议定稿（1–2 天）

**做什么**：把已经在跑的“双层协议”写成 `docs/evidence-protocol.md` 并套满 14 项。

| 层 | 问什么 | 判据 |
|---|---|---|
| L1 扳动层 | 消融真的改了它声称改的量吗？ | 扳动量方向正确 |
| L2 后果层 | 改了之后行为/功能有无变化？ | 配对置换 p<0.05 且方向符合预期 |
| 闸门 | L1 失败 → 结论作废；L1 过 + L2 阴性 → 只算架构层 | — |

**产出**：14 项每项都有“扳动量 / 行为效应 / 判定”三列（现在只覆盖 8 项）。

**闸门**：若某项 L1 判定为“没接上”，先修实现，不许先报阴性。

### Step 2｜O 流（2–3 天）——这是打开“能不能给 credence”的门

**做什么**：

1. 用 `evidence/blind_review.md` 的材料，招募 ≥2 名独立评分者，**先固定 rubric 再评**；
2. 评两件事：(a) 转写文本里有没有“报告自己状态”的内容；(b) 能否分辨 baseline 与消融组的转写；
3. 报 **评分者间一致性**（Cohen's κ 或 Krippendorff α）。

**产出**：κ 值 + 一份“能/不能分辨”的结论。

**闸门**：κ < 0.4 → O 流不可用，如实写“本项无证据”，**不许**拿它支持任何主张。
若能分辨且 κ 够 → 这是第一条“可判死”的观察者侧证据。

**为什么排第二**：它是形式阻塞，且成本最低、不依赖任何架构改动。

### Step 3｜临界性铰链（约 1 周）

**做什么**：在现有 trace 上测三个量（**不改架构、不调参**）：

1. branching ratio σ（每个 tick 的“激活数”/上一 tick 的“激活数”，阈值扫描）
2. 雪崩尺寸分布（是否近似幂律，指数）
3. 动态范围（dynamic range, dB）

**预注册判据（先写死）**：σ ∈ [0.9, 1.1] 且雪崩指数落在 1.3–1.7 → 临界性主张成立；
否则**关闭**，并写明“本系统不在临界区”。

**产出**：`docs/criticality-results.md` + 证据 JSON。

**闸门**：**不许把系统调到临界**。那是 tuning-to-pass，我们已经禁过一次（效价三版）。

### Step 4｜拆观测（1–2 周，可选、最后做）

**做什么**：让每个模块只看局部（vision 只 3×3、danger 只邻近报警、intero 只身体、
temporal 只上一动作），信息必须经工作空间拼。这是 GWT-3 唯一可能翻正的路径。

**代价**：partial 模式的全部基线作废（pomdp/planner 要重跑），性能可能掉。

**闸门**：先在预注册里写死“正对照必须成立”（random 显著差于 baseline），
否则判任务无效，不判 GWT-3。

## 4. 什么时候可以说“强候选”

四条同时满足：

1. TCAS 四流齐（B/M/P/O 都有数据，O 流有 κ）
2. 至少一条可证伪的预测被真测过（临界性 σ，或 do() 干预的跨任务复现）
3. 两档证据如实报（架构层 11/14、功能层 6/14）
4. 阴性清单完整、预注册可查、跑数可复现

满足 → 可以给**带范围的** credence band（“在 GWT/HOT 口径下……”）。
不满足 → 只能说“L1/L2 功能候选，L3 无证据”，不能说强候选。

---

## 5. 明确不做的事

1. 不调到通过（调阈值、调代价、调 seed 数换结论）
2. 不加没有扳动量的模块（每加一个都要过 Step 1 的双层协议）
3. 不把架构层当功能层（11/14 ≠ 6/14）
4. 不在 EI 上加码（三条路已关闭：填充伪影 / 无分辨力 / 宏观可分解）

---

## 6. 补充模块的处置（DCM / 临界 / 双向 / TRO / ACA）

| 项 | 性质 | 放哪 | 前置 |
|---|---|---|---|
| DCM | 测量方法（有效连接） | Step 3 之后当分析层 | 有稳定 trace |
| 双向临界 | 半测量 + 半架构 | 测量并入 Step 3；双向部分只能在拆观测之后、以旁路形式重试 | Step 4 |
| TRO 分离任务 | 任务设计（分开 dyadic / solipsistic） | Step 4 之后 | 需要一个“世界可预测但整合不进去”的任务 |
| ACA 双层协议 | 待定（表述未澄清） | 暂挂 | 用户给出处 |

**共同前提**：每个补充模块都必须自带“不做就变差”的任务 + 一条 L1 扳动量，
否则一律记作架构层，不进功能层计数。
