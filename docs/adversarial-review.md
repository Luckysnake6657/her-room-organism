# 外部审稿意见与我们的整改（2026-10-26）

用 DeepSeek API 让模型扮演严格审稿人，对我们的证据包提最致命的反对意见。
原文：`lab/gwa/evidence/review.md`。下面逐条记录**它说得对不对**，以及我们做了什么。

---

## 五条反对意见

1. **Φ 被自己的零模型判死**：0.004–0.011 与打乱零模型不可区分；60 个玩具网络的 ρ=0.648 不能外推；
   而且 σ=0.42 亚临界与"Φ 峰在混沌区"自相矛盾。
2. **容量 1 工作空间 + do() 只证明"扰动瓶颈会改变输出"**：缺中介分析、缺等参数量对照、缺跨任务保持。
3. **视觉消融是感觉剥夺混淆**：没有 sham lesion、没有等带宽随机通道对照。
4. **Butlin 14 项打分没有测量效度**：自定义阈值、无评分者信度、无多重比较校正。
5. **统计链条断裂**：伪重复、多次干预未校正、跨尺度外推。

## 我们验收了哪条：第 3 条，**成立，而且是致命的**

加了**等带宽假损伤**（`vision_sham`：视野换成随机值、方向换成随机方向，通道保留）：

| 条件 | 进食 | 危险 | 死亡 |
|---|---|---|---|
| baseline | 3.73 | 3.08 | 7% |
| interoception_off | 3.67 | 2.45 | 17% |
| **vision_sham（随机内容）** | **3.05** | **10.20** | **75%** |
| vision_off（真去掉） | 2.80 | 8.97 | 68% |

**随机内容造成的损害与完全去掉几乎一样**（3.05 vs 2.80；10.20 vs 8.97；75% vs 68%）。

也就是说：我们之前那句"去掉视觉模块 → 性能崩塌 → 视觉模块有功能"**是伪结论**。
真实情况是：**这个通道是主导输入，扰动它就崩，与它携带什么信息无关**。

## 于是 GWT-1 的证据必须降级

- 原表述："视觉通道消融导致进食 −1.12、危险 +6.58、死亡 +62 点（p=5e-5）"
- **修正为**："视觉通道是主导输入；去掉或**随机化**它都会导致同样的崩塌（3.05 vs 2.80），
  所以该消融只证明**通道必要性**，不证明**功能特异性**。"
- 另附：`interoception_off` 几乎没有影响（3.67 vs 3.73），危险甚至略降——
  说明各模块的权重高度不均，谈不上"多个专门系统并行"的强证据。

**结论：GWT-1 的功能层证据从"成立"降为"仅通道必要性"。**

## 我们没验收但必须写进 limitations 的

- 第 1 条：Φ 那条我们自己早就写了"与零模型不可区分"，但"σ 亚临界 vs Φ 峰在混沌区"
  这个自相矛盾确实没写清楚——**目标 agent 不在高 Φ 区，这点要明说**
- 第 2 条：缺中介分析（广播内容是否真的流入各模块），我们只有"扰动改变输出"
- 第 4 条：14 项打分没有第二评分者——**这条可以用 LLM 做独立盲评来补**
- 第 5 条：伪重复与多重比较，需要在方法节显式处理

## 这条经验

**用外部模型做对抗审稿，比我们自己反复跑实验更有效**：它一眼看出 sham control 缺失，
而我们自己跑了 60 个 seed 都没意识到。
