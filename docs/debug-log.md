## 两个教训

### 1. 最危险的不是"没效果"，是"效果看起来对"

P5 就是这类：`max_tokens=160` 让回复变成 0 字，
**在"自尊低 → 话短"的语境里，这看起来完全像是情绪生效了。**
如果没有盯着空字符串查，这个 bug 会一直被当成效果。

P7 同理：依恋顶满 1.00 看起来像"她很想你"，其实是常数写错了。

### 2. 阈值必须用真实数据定，不能拍

P8 第一版我拍了 0.5。实测同一问题的两种问法是 **0.172**——阈值高了三倍，
等于没开检测。先用真实翻车的那两句量出 0.172，再定 0.12 + 共享 bigram ≥10，
并把这**两句原文**写进自检当回归用例。
