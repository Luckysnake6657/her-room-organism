# 预注册：感受自我（四层）

2026-10-30。目标：从"状态报告"变成"她自己的感受"，不造假。

## 文献

- 内感受推断：情绪=身体信号+预测（Seth 2013；Barrett 2017；[Interoceptive AI](https://discovery.ucl.ac.uk/10230924/1/Friston_NMI%20manuscript-V16.pdf)）
- 评价先行：事件按目标/需求评价才产生情绪（[Third-Person Appraisal Agent, EMNLP 2025](https://aclanthology.org/2025.findings-emnlp.1288/)）
- 稳态优先级：需求竞争决定当下最要紧的（[Homeostatic Prioritization](https://browse-export.arxiv.org/pdf/2608.04232)）
- 叙事连续性：持久 agent 需要自传层（[Narrative Self-Continuity](https://zenodo.org/records/20743926)）

## 四层

1. **内感受推断**：六状态 + 事件评价 → 效价/唤醒/词/置信
2. **二阶态度**：想要 / 不想要（如"想有人说话"）
3. **叙事**：周度第一人称自述
4. **表达**：第一人称、允许模糊、**不编原因**、用她历史词表

## 判据

- 盲读"像她自己的感受" ≥ 60%（对比现状）
- **编原因率 = 0**（不出现"因为你…"这类无依据因果）
- 同情境重复 3 次，相似度 < 0.6
- 置信低时必须用模糊说法
