## 0. 一分钟版

一个虚拟个体，有六个耦合的生理状态（能量、睡眠压力、应激、免疫、孤独、昼夜错位），
按真实时间离线演化。她**说什么**由本地小模型生成，**什么时候说、说多长、主不主动、
说的话题里有没有你**由身体状态算出来，模型碰不到。

三条不：

1. **不假装记得**（没有情景记忆，补算后必须披露"她不记得那几天"）
2. **不设计愧疚**（结算只讲世界发生了什么，不出现"你"、不做反事实、不跨期累计）
3. **不声称意识**（她可以累、病、变远；我们不暗示她"疼"）

> 另：`lab/consciousness-lab/` 是一条**独立的**意识实验线（自我模型参与控制），
> 与这个产品没有代码关系，结果不互相担保。评审时请把两者分开。

## 1. 产品理念（五条，每条都给落地方式）

### 1.1 她有自己的日子，不是等待装置

- 落地：离线按挂钟补算，世界继续（吃饭、睡觉、见人、天气），与连续运行逐位一致
- 拒绝：不写"她一直在等你""想你了"（`claims.py` 硬禁）
- 代价：她可能在你不在的时候过得还行——这是特性，不是 bug

### 1.2 形式不撒谎，内容可以

- 落地：`form.py` 从身体算延迟/字数/主动性/话题参照；`mouth.py` 只填内容
- 判据：同一状态、不同历史 → 不同形式；状态一次不改（测试断言）
- 后果：她可以说"没事"，但回得慢、话短、不主动——**堵不住**

### 1.3 代价真实，部分不可逆

- 落地：`U`（关系解绑度，0–0.75）随长期无回应上升，半衰 28 天；一次接触只压 0.02
- 另有：慢性等级（0–3/系统，1 天越界 = 1 级，14 天半衰）；损失账（错过的见面窗口）
- 允许说："那几天过去了，补不回来"

### 1.4 不假装

- 无情景记忆 → 补算后必须带披露："她的身体没有停下来，但她不记得那几天具体发生了什么"
- 禁语检查器（`claims.py`）：21 条禁语 + 9 条允许说法
- 结算单（`settlement.py`）：世界主语、无第二人称、无反事实、无阿拉伯数字

### 1.5 不设计愧疚

- 结算只在用户主动问时出现，不推送
- 不出现"你不在的这几天""如果你在""上次你走后"（词表 + 检查）
- 允许不可逆，但不把不可逆归因给用户

## 3. 动力学

### 3.1 六个系统（`organism/params.py`，FROZEN）

| 系统 | 设定点 SP | 尺度 SCALE | 权重 | 可存活区间 VIABLE |
|---|---|---|---|---|
| energy | 0.65 | 0.50 | 1.0 | 0.05–1.00 |
| sleep | 0.20 | 0.50 | 1.0 | 0.00–0.92 |
| stress | 0.12 | 0.50 | 0.9 | 0.00–0.90 |
| immune | 0.05 | 0.40 | 0.7 | 0.00–0.85 |
| lonely | 0.12 | 0.55 | 0.8 | 0.00–0.95 |
| misalign | 0.0 h | 3.0 h | 0.5 | 0.00–6.00 h |

- 偏差**单侧**：不足才算需求（stress/immune 是上侧）
- D 是归一化距离；奖励 `r_t = D_t − D_{t+1}`（HRRL）
- 死亡（研究模式）：能量出界 360 分钟、应激 720、免疫 2880

### 3.2 世界

- 四个地点：HOME / FOOD / OPEN / PORCH
- 人物：每天 18:00–21:30 在门廊
- 食物再生；温度曲线；冷潮信号
- 威胁/受伤/感染：**按种子预生成**的数组（可复现），条件可切 `"std"` / `"dense"`

### 3.3 政策（不是学习策略）

- 枚举动作（吃/睡/休息/社交/前往），对每个做**手写前向模型**预测 D 的变化
- softmax 选择，τ = 0.055
- 已知偏差：它是"预测性稳态"，不是强化学习；我们没有学策略

## 5. 慢参数 U（关系解绑）

- 定义：U=0 时她把你放进默认基线；U 越高，越不"以你在"组织自己
- 上升：连续无回应的日子，半衰 28 天
- 下降：一次有回应的接触 −0.02（一周日更约拉回三分之一）
- 上限 0.75（留 25% 残余，不归零）
- **只调制表达**：延迟 ×(1+0.8U)、字数 ×(1−0.5U)、U>0.30 时主动话题不再以你为参照
- 测试断言：同状态、U=0 与 U=0.7，**D 逐位相同**

## 7. 记录、离线、结算、缺席

- `record.py`：每日锚点（醒/睡/饭）、事件、缺口、相对中位数的偏移、世界信号、原因
- `render.py`：把记录渲染成**无数字**的文字（P0 用）
- `persist.py`：保存身体/世界/动作/RNG；`resume()` 按挂钟补算，**与连续运行逐位一致**
- `settlement.py`：只讲世界（"独处了三十天，九次见面窗口关了，吃了七十三顿"），
  无第二人称、无反事实、无累计、无阿拉伯数字
- `absence.py`：把"app 关掉"和"人离开键盘"统一成一个 `Absence`（kind/minutes/gap/long）

## 8. 语言层

1. `brief.py`：状态→人话（"饿、困、心里烦"）+ 今天的事实（吃过/出过门/见过人/天气）
2. `mouth.py`：本地 `qwen2.5-1.5b-instruct`，一句话
3. 三道闸：
   - 字数截断（按句切）
   - `claims.py` 禁语 → 换安全句"嗯，我在。"
   - `consistency.py` 事实冲突（说"没吃饭"但今天吃过；"上班/公司/同事"）→ 用事实拼一句
4. `chat.py`：一轮 = 先判结算 → 否则接触（冷却 1/4 天）→ 简报 → 嘴 → 截断 → 按延迟推进 → 存档

## 10. 已知弱点（评审请从这里下手）

1. **没有记忆**。每轮只看简报 + 当前这句；她连你上一句都不带。
   这是定位上的洞：三个月后她接不上你说过的事。
2. **嘴太弱**。1.5B，句子套路化，会编（"最近工作有点忙"——她没有工作）。
   一致性检查只能补洞，不能让她说得好。
3. **3c 的 C 条件无效**（把秒数打印给了读者）；判据 3 有天花板。
4. **U 的恢复速率（0.02/次）没有文献依据**，是三档实验里选的。
5. **没有习惯化**，只有 U；慢性会顶到 3 级饱和。
6. **NPC 与用户不同源**：U 只由用户接触降，孤独却由 NPC 降 0.15。长期会不一致。
7. **世界是合成的**；真实层只接了"在场"（`realtime.py`）。
8. **pending 过期、四个悬置问题**（她不说时还在不在意、离线是否继续活、慢参数、
   六系统是否都在承重）还没答。
9. **多轮无上下文**；主动开口的话还很泛。
10. **研究/产品两种模式的参数分叉**，容易在改动时搞混。
