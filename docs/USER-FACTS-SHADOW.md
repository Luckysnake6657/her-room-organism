# 影子用户事实：抽取与自测

2026-10-30。第 10 轮。只写独立本子，不动她的记忆。

## 文献

- Angeli et al. 2015：OpenIE，把句子抽成原子事实
- Park et al. 2023：从经历里做反思/记忆抽取
- Mem0 2024：面向助手的事实抽取与更新

## 做法

`organism/user_facts.py`：

- 只读 `messages.jsonl` 里**他**发的消息
- 按句切；保留 8–60 字、含"我/你"、含动作/状态词、非问句、非工程日志
- 把"我"改写成"他"
- 写入 `evidence/p3/shadow_userfacts/notebook.json`（source=user_shadow）

## 结果

| 项 | 值 |
|---|---|
| 抽出的用户事实 | **32 条** |
| 自测（事实→问句→检索） | **27/28 = 96.4%** |
| 本子外问题误召回 | **0/6** |

**关键坑**：检索有 `THETA=0.7` 的置信门槛，影子条目一开始 0.6 被整段过滤，召回 0；
调到 0.75 后正常。说明**低置信事实在现行检索里是不可见的**。

## 解读

1. 管道通了：抽出来 → 存进去 → 问得到。
2. 但**量太少**：899 条消息只抽出 32 条事实，规则太保守；真实覆盖仍不足。
3. 自测是"自己出题"，不等于真实问法；n 也小。
4. 置信门槛意味着：要么抽得准（≥0.7），要么调检索策略，不能靠"先存着"。

## 下一步

1. 用 LLM 抽取（而不是规则），提高量与改写质量
2. 影子本子扩到 200+ 条，再用真实短问法测覆盖
3. 确认有效后，再谈并入她的本子（逐条/分批确认）
