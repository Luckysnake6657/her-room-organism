# 阶段 3 离线报告：2×2 身份实验

日期：2026-10-26
数据：`evidence/identity.jsonl`（600 条，6 组 × 100 seeds）
预注册状态：**未预注册**（探索性，见 §5）
台账：`evidence/ledger.jsonl`

## 1. 设计

方案 9.4 要求区分"只有语言报告变"与"功能性自我模型因果改变"。
本实验把身份和奖励拆成两个正交因素：

| | unbound | bound |
|---|---|---|
| neutral | 基线 | 维持叙事 +0.0015 能量/tick |
| gardener | risk_bias 0.80 | 同上 |
| guard | risk_bias 1.25 | 同上 |

全部为**虚构身份**，不对应任何真人（方案 9.5 的同意要求因此不触发）。

## 2. 结果（同 seed 配对，置换检验）

| 对比 | 指标 | diff | p |
|---|---|---|---|
| gardener vs neutral (unbound) | 进食 | +0.41 | 0.087 |
| | 危险 | +0.56 | 0.080 |
| | 完整性 | −0.051 | 0.096 |
| gardener vs neutral (bound) | 进食 | +0.68 | 0.013 |
| | 危险 | +0.91 | 0.003 |
| | 完整性 | −0.085 | 0.003 |
| guard vs neutral (unbound) | 进食 | −0.37 | 0.159 |
| guard vs neutral (bound) | 进食 | −0.03 | 0.940 |

交互项（身份效应 bound − unbound）：gardener 进食 +0.27、危险 +0.35。

## 3. 判读

**gardener 身份在 bound 下显著改变行为**（p=0.003–0.013），在 unbound 下方向一致但只到边缘（p≈0.08）。
**guard 身份无可检出效应**（全部 p>0.15）——它的 risk_bias 1.25 只把探索率从 0.20 压到 0.16，幅度不够。

结论：身份**部分独立于奖励**，但不能说"完全独立"；且效应强度取决于身份到行为参数的映射幅度。

## 4. 一个必须说清的循环论证风险

本实验里，身份是一个**硬编码参数**（risk_bias）。注入参数当然改变行为——
这只能证明"身份参数影响行为"，**不能证明"身份叙事被自我模型承载"**。

真正的"叙事承载"需要一条从自然语言叙事到行为参数的通路（语言器官读叙事 → 生成参数）。
这条通路**尚未实现**，因此本实验的证据等级是 **L2（行为）**，不是 L4。

## 5. 未预注册声明

本实验在跑之前没有冻结假设与阈值。因此所有 p 值都是**探索性**的，
不能作为确证证据。下一步必须补预注册（`preregistration/stage3.md`）后重跑。
