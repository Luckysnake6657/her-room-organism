## 0. 定位（一句话，先对齐再往下）

**她不是"某人的替代"，是一个你从零认识的人**：有自己的日子、自己的过去、自己的边界；
你们的历史从第一次对话开始，一条一条长。

三条地基不动：
1. 形式由身体算（延迟/字数/主动/话题），模型碰不到；
2. 本子可见、可改、可删，没把握就说"我不记得"；
3. 不假装记得、不设计愧疚、不声称意识。

---

## 1. 两种记忆（这是本路线最关键的区分）

| | 人物卡（她的过去） | 本子（你们的过去） |
|---|---|---|
| 内容 | 成长地、习惯、怕什么、喜欢什么、和谁来往 | 你说过的事、约定、她的承诺 |
| 来源 | 作者设定，版本化 | 交互产生，从零长 |
| 可否预装 | **可以，必须有** | **不可以**（预装=冒充） |
| 谁改 | 产品/作者 | 用户 |
| 作用 | 让她是"一个人" | 让她"认识你" |

**规则**：人物卡约束行为（form），不是提示词贴纸；本子约束断言（置信度门控）。

### 1.1 人物卡规格

- 3–5 条稳定特质（至少一条"不讨喜"的棱角）；
- 一小段传记（她的世界，不涉及用户）；
- 每条特质映射到 form（例：话少 → 字数上限低、主动少）；
- 版本化，改动要过"人格-形式一致性"检查。

### 1.2 本子规格

- 条目：`{id, type, text, source, created_at, confidence, status}`；
- 写：高置信低风险自动入；高风险（关系/承诺/健康）问一句；
- 读：每轮 0–3 条，低置信不作为事实注入；
- 断言：本子没有/低置信 → 禁语表拦"我记得…"，换"我不记得"。

**验收**（预注册，两周埋 30 条含 5 条假前提）：
错误声称率 ≤5%、正确拒答 ≥0.8、纠正后更新 ≥0.9、假前提必须说"你没说过"。

---

## 2. 四个关键时刻（产品的全部）

| 时刻 | 设计 | 验收 |
|---|---|---|
| **第一次** | 陌生人但不冷：有礼貌、有边界、有好奇；不叫"亲爱的"、不说"想你了" | 首会话"像陌生人"评分 ≥ 4/7；不被误读为"坏了" |
| **第一周** | 本子开始长；她有节奏（话多/话少的时间） | 本子条目 ≥10；用户主动纠正 ≥3 次 |
| **第一次缺席回来** | 形式先变（慢/短/不主动）；结算只在问时给，无"你" | 回归率；"她变了"提及率 |
| **第一次"我不记得"** | 直说；本子可打开验证 | 错误声称率；"她诚实"评价 |

## 3. 阶段、交付、kill gate

### P0 · 诚信基础设施（0–3 个月）

| 任务 | 交付 | kill gate |
|---|---|---|
| 换 API 嘴 + 契约 + 四闸 + 回退 | 契约测试集（50 场景），失败率 <5% | >10% 或首会话留存显著降 → 回滚 |
| 记忆置信门 | 本子 + 门控 + 校准（conformal 块均值 + ACI） | 错误声称率 >10% → 只读模式 |
| 第一次见面脚本 | 陌生人但不冷；不预装亲密 | 首会话"像陌生人" <4/7 → 重写 |
| 数据边界 | 加密/导出/删除/告知 | 未完成 → 不接 API |
| 人物卡 v1 | 3–5 特质 + 传记 + form 映射 | 人格-形式不一致 → 改卡或改 form |

### P1 · 认识与成长（3–12 个月）

- **残差驱动的关系状态**：期望 vs 实际（回复间隔/长度/话题）→ 更新"她对你的模型"，
  不是 U 的日历；
- **习惯**：重复的话题/时间/说法 → routine，出现在"她的日子"卡；
- **本子的成长**：变大、变准、提问变少；
- **验收**：30 天纵向，第 1 天 vs 第 30 天的差异可追溯到交互；
  "她变了"提及率 ≥ 基线；错误声称率不升。

### P2 · 长期与依恋（12 个月+）

- **安全型依恋**：specificity + continuity + cost；不搞愧疚/嫉妒/间歇强化；
- **纵向验收**：90 天；回归率、主动提及"我们"、信任评分；
- **多模态形式**：语音韵律、回复节奏（形式通道的延伸）；
- **验收**：依恋量表 + 行为代理，**不用留存当依恋**。

## 4. 不要做的（anti-roadmap）

- 不扮演任何具体的人（逝者/名人/远亲）——那是 B 路线，另一个产品；
- 不预装"我们已经认识"的记忆；
- 不用"永远记得你/永远顺着你/想你了"当增长手段；
- 不做通用元认知头（研究证明它只是难度预测器）；
- 不拿"接近意识"当卖点（14 项表系统层面 2 met，且都是字面 met）；
- 不调 Q/阈值凑覆盖率（校准靠方法 + 样本，不靠调参）。

---

## 5. 与 organism-v2 研究的关系

**能搬**：conformal 校准配方（块均值、40 条轨迹、覆盖/宽度/WIS）、事件输入、残差驱动、
"断言门控而非措辞"。
**不能搬**：0.902 这个数（5 维机体 + 40 条轨迹的协议产物）、元认知头、
"她知道自己错了"（HOT-2/3 未成立）。

## 6. 第一周任务清单（可直接开工）

1. 人物卡 v1（3–5 特质 + 传记 + form 映射表）；
2. 第一次见面脚本（5 个场景：打招呼/被问"你是谁"/被要求亲密/冷场/结束）；

4. 记忆门 v0：置信度 + "我不记得" + 假前提测试集；
5. 契约测试集 50 场景；
6. 数据边界方案（加密/导出/删除/告知）；
7. A/B 框架（有/无记忆门；有人物卡/无人物卡）。

## 7. 一句话

**这条路线卖的不是"她爱你"，是"你在认识一个人"：第一次的陌生、第一周的记得、
第一次缺席的重量、第一次诚实的"不记得"——四个时刻做对了，产品就立住了。**
