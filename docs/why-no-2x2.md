# 为什么不做那个 2×2「假核对照」（2026-10-27）

上一轮我说要做 2×2（真核 / 假核 × 同一语言 / 模板语言），用它回答"核在不在承重"。
**想清楚之后我决定不做，理由如下。**

---

## 1. 如果语言用模板渲染，这个实验的结果是构造出来的

模板渲染器是"状态 → 固定句子"的确定性函数。那么：

- 真核：状态由事件驱动 → 句子跟着事件变
- 假核：状态被打乱 → 句子跟着乱

**两者必然可分。** 这不是发现，这是把耦合关系写进了代码再拿它当证据。
和 A0 那次"假核 300/300 全塌成 reflect"是同一个毛病：**显著，但无意义。**

## 2. 如果语言用 LLM，答案我们已经测过了

`lab-home/state_ablation.json`：

| 条件 | 长度 |
|---|---|
| 高自尊 | 81 |
| 中 | 188 |
| 低自尊 | 53 |
| **无状态块** | 124 |

条件间差异与条件内噪声同量级。**LLM 那边已经答了：状态几乎不起作用。**

## 3. 所以 2×2 两个格子都是空的

| | 真核 | 假核 |
|---|---|---|
| 模板语言 | 差异由构造保证 → 无信息 | 同左 |
| LLM 语言 | 差异淹没在噪声里 → 已测 | 同左 |

**做一个注定"显著但推不出任何东西"的实验，是这个项目一直在避免的事。**

---

## 4. 那"核在不在承重"这个问题还能怎么问？

能问，但答案不是靠对照，而是靠**测量**：

> **不是"换掉核会不会不一样"（一定会），而是"这个核在因果结构上有没有东西"。**

也就是 Φ、λ、以及"拆开就做不成事"（那是 B 线，已关闭）。

**结论：这个问题只能由 Φ 和 B 类实验回答，2×2 回答不了。**
把它从待办里删掉，不留一个假任务在上面。

---

按 `docs/GOAL.md` 的优先级：**G3 > G1**。下一步做：

- **B3 主动开口**（验收第 4 条）
- **B4 情绪硬化**（验收第 3 条：哄不好、修复要时间）
- **P4 数据边界**

这三件都是可见的、不需要任何新研究。
