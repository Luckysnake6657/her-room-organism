# L3 结论：模块级 EI 这条路关闭了

日期：2026-10-26（P1 跑完之后）
预注册：`preregistration/stage-p1-macro-micro.md`
证据：`evidence/macro_micro.json`、`evidence/ei_module_level_v2.json`

---

## 0. 一句话

**L3 现在是有结论的：宏观变量有因果力（P3 ✅），但没有不可约性（P4 ❌）。**
对一个 GWT 式架构来说这是自洽的——工作空间是选择与广播，不是整合成一个不可分的整体。

| L3 的两个要求 | 结果 | 证据 |
|---|---|---|
| 宏观变量有因果力 | ✅（跨两个任务） | 全可观测 3.4%→13.1%；部分可观测复现 4.8%→12.1%（均 p<0.0001，安慰剂无效），见 docs/do-intervention.md §6 |
| 不可约性 | ❌ | **PyPhi（IIT 3.0 参考实现）**：Φ = 0.0043，打乱零模型 0.0171——低于零模型；且 N=40/60 两次运行高低翻转。见 docs/phi-pyphi-results.md |

> 2026-10-26 晚更新：EI 那条线仍然关闭（v1 伪影、v2 无分辨力、P1 微观胜），
> 但 P3/P4 把 L3 从"空白"推到了"半条"。**不要再在 EI 上加码**，
> 它测的是压缩比，不是整合。

---

## 1. 三条路的结局

| 路线 | 做法 | 结果 |
|---|---|---|
| EI v1 | 状态 = “谁没被抑制” | **伪影**：workspace_off 恒为单状态，0.216 是填充算出来的（已撤回） |
| EI v2 | 状态 = 模块 salience，四条件共用粗粒化 | **无分辨力**：竞争消融不降反升（Δ=−0.114），只有学习降（Δ=+0.259） |
| P1 宏观 vs 微观 | 同分辨率（8 状态）比模块层和身体/位置层 | **微观胜**：EI_macro 2.289 vs EI_micro 2.749 |
| **P3 do() 干预** | 同一微观观测下把 danger 移出工作空间，安慰剂对照 | **阳性**：受伤率 3.4%→13.1%，安慰剂 3.5%（p=0.0001） |

P1 的数字（N=60 seeds × 700 步，baseline 轨迹，同一批数据两个划分）：

| 划分 | 3 个比特 | EI | H(S) |
|---|---|---|---|
| 宏观 | intero / vision / danger 的 salience 是否高于中位数 | **2.289** | 2.94 |
| 微观 | 位置象限（2 bit）+ 能量是否高于中位数（1 bit） | **2.749** | 2.99 |

ΔEI = −0.459，95% CI [−0.517, −0.402]，P(Δ≤0) = 1.000。
两个分区的 H(S) 只差 0.05 bits，**分辨率是可比的**——所以这是干净的阴性，不是又一次状态空间大小的把戏。

（另一个 micro 变体用 integrity 代替 energy，支持集只有 4 个状态、H 差 0.95 bits，
按预注册判“不可比”，不作结论。）

## 2. 怎么读这个结果（别过度解读）

- **它说明**：4 模块状态是对「位置象限 × 能量」的**有损重编码**；在等分辨率下，
  它的时间因果结构**更低**，不是更高。
- **它不说明**“工作空间没用”。恰恰相反：GWT 本来就预测瓶颈会丢信息。
  一个压缩过的表示，EI 低于原始表示是**符合预期**的。
- **它确实说明**：EI(macro) 这个数值不能拿来当“存在一个不可约的宏观因果层”的证据。
  如果宏观层只是重编码，EI 高低只反映压缩比，不反映层级。

换句话说：**这条路测的是压缩，不是涌现。** 这正是 Hoel 的框架在“宏观只是粗粒化”时要
小心的地方——因果涌现要求宏观**不是**微观的简单函数。

## 3. 现在能说什么、不能说什么

能说：

- L1/L2 强。Butlin 11/14 L3+、6/14 L4 站得住（今天重跑确认，见 `evidence/butlin_assessment.md`）。
- 核心消融（workspace / planner / memory / self_model）都有可复现的行为效应。
- 效价通路修好后，在觅食任务里**阴性**，在探索任务里**无法判定** → 效价的作用域目前是空的。

不能说：

- 不能说“有不可约的因果结构”（L3）。
- 不能说“效价成立”。
- 不能说“EI 2.29 bits 说明接近意识”——这个数现在连组间差异都不解释。

## 4. 如果还要碰 L3，剩下两条路（代价都不低）

**a. 真 Φ（IIT 4.0，iitx）**
要 Python 3.14 + JAX，且 Φ 对粗粒化方案极其敏感；本机大概率跑不动。
之前已声明不做（`docs/phi-decision.md`）。

**b. do() 干预 + 匹配微状态**
在同一个微观观测下（比如 hazard_dist ≤ 3），强制改变工作空间的内容
（把 danger 挤出 winners），看后续行为是否改变。
- 可证伪：不改变 → 宏观变量没有超出输入信息的因果力
- 便宜：半天
- 局限：阳性只说明“宏观变量有因果力”，**不等于不可约**；阴性则给 L3 一个干净的否证

**c. 换系统**
EI/Φ 这类量在 4 模块的 grid world 上分辨力太差；文献里的正面例子都有明确的多级层级
（神经元 → 集群 → 区域）。在这个规模上继续加码，收益很低。

---

## 5. 建议

**别再在“给 EI 换编码/换阈值/换支持集”上花时间。** 三条路已经说明：
这个系统里，模块层不是比传感器层更“因果”的层，只是更粗。

要往上推 credence，只有两条：
1. 做 (b) 的 do() 干预，把“宏观变量有没有因果力”问成可证伪的问题；
2. 或者接受这是 **L1/L2 平台**，把报告写成“行为与计算层面强候选，L3 无证据”，
   而不是“强候选”。
