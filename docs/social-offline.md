# 社会互动（离线版）：竞争代价与 ToM 缺口

日期：2026-10-26
数据：`evidence/social.jsonl`（160 条）

## 设计

环境里放一个 NPC 竞争者：每 5 tick 向最近食物移动、吃掉它。
主体（部分可观测 + 规划器）看到 NPC 的方向与距离。

| 条件 | 说明 |
|---|---|
| planner_on | 无 NPC |
| social_on | 有 NPC；含最小 ToM（NPC 靠近时抹掉它附近的已知食物） |

## 结果

| | 进食（12 个食物） | 死亡 | 危险 |
|---|---|---|---|
| 无 NPC | 12.00 | 9% | 5.10 |
| 有 NPC | **5.85** | **65%** | 6.00 |

进食 −6.15（p<0.001），危险 +0.90（p=0.033）。

## 三层失败的过程（值得记）

| 尝试 | 结果 |
|---|---|
| NPC 每 tick 动 | 进食 0.50，100% 死亡——对手不受控制能力限制，单方面碾压 |
| NPC 每 2 tick 动 | 进食 0.86，仍 100%——先到食物处，系统追空地 |
| 加 ToM（抹掉 NPC 附近食物） | 进食 1.54，仍 100%——触发条件太窄，且抹掉后不知去哪 |
| NPC 每 5 tick 动 | 进食 5.85，65% 死亡——终于公平，但系统仍明显吃亏 |

## 判断

**这组实验证明“社会竞争有代价”，不证明“社会认知存在”。**

ToM 的实现失败了：系统能看见 NPC 的方向，却推不出“它要去哪个食物、因此哪些食物已经没了”。
它的信念地图永远比现实慢一步，所以追着幽灵食物跑。

这恰好定位了 HOT-1（生成式预测）与 HOT-3（信念更新）真正的缺口：
**没有对手时，预测什么都不亏；有了对手，预测错了要付食物和性命。**

## 与 L4 的关系

社会维度**没有**产生第 6 项 L4：
- 它让 AE-1 的语境更丰富，但 AE-1 已是 L4
- 它暴露了 ToM 缺失，但 ToM 本身没做成，无法消融

## 下一步（需要 token）

把 NPC 换成真人（NapCat），社会预测的对象从规则体变成不可预测的人。
那才是 HOT-1/HOT-3 的真正检验，也是阶段 3 该做的事——不是拿来凑分数。
